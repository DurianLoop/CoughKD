# 5.50 Public External Target Scouting

## 本轮目的

当前最大的 ICASSP 证据缺口仍然是第二个足够强的外部目标。Cambridge / ComParE 需要申请，DiCOVA 可能需要旧 challenge 访问。因此本轮继续检索是否存在可直接获取、比 Virufy 更有实验价值的公开 cough/respiratory 数据集。

## 候选结论

### 1. Cambridge COVID-19 Sounds / ComParE CCS

状态：仍然是最高优先级。

原因：

- COVID cough binary target；
- 规模大；
- 和 Coswara/COUGHVID 相比更适合作为第二独立外部目标；
- 可以直接支撑当前 CoughKD-ShiftAudit 主线。

限制：需要 Data Access / DTA，不能由脚本直接拉取。

### 2. CODA TB cough dataset

状态：最有价值的非 COVID disease-transfer target。

原因：

- 咳嗽音频 + 疾病相关标签；
- 和 COVID 任务语义不同，适合作为 generic cough deployment reliability 的 task-shift 证据；
- 如果 Cambridge 迟迟拿不到，它比 wet/dry 或事件检测数据更接近医学筛查场景。

限制：需要 Synapse / data access，不是直接 GitHub 下载。

写法：不能说 COVID external validation，只能说 non-COVID cough disease-transfer stress test。

### 3. FluSense / Hugging Face respiratory event audio

状态：公开但任务不匹配。

原因：

- 公开、规模比 Virufy 大；
- 标签是 cough/sneeze/speech/noise 等事件，不是疾病；
- 可以用于 representation / probe / deployment robustness stress test。

限制：不能把 cough-event detection 直接当作 COVID 或疾病筛查验证；如果使用，论文 claim 需要扩大为 generic cough/audio deployment reliability。

### 4. Mixed-source processed COVID cough datasets

状态：不推荐用于主 claim。

原因：

- 很多公开镜像混合 Coswara / COUGHVID / Cambridge / Kaggle 来源；
- overlap 和 leakage 风险高；
- 可能不清楚许可和原始 split。

用途：最多用于脚本 smoke，不作为 external validation。

## 新增脚本

为了未来快速接 Hugging Face 音频数据，新增：

```text
scripts/build_hf_audio_manifest.py
```

它可以：

- 从 HF audio dataset 读取 audio column；
- 保存为本地 wav；
- 生成 CoughKD-style manifest；
- 支持 `label-map`、`keep-labels`、`max-records`、`streaming`。

语法检查：

```powershell
D:\conda\envs\CoughKD\python.exe -B -c "import ast; from pathlib import Path; ast.parse(Path('scripts/build_hf_audio_manifest.py').read_text(encoding='utf-8')); print('syntax_ok')"
```

结果：`syntax_ok`。

注意：这个脚本需要可选依赖：

```powershell
pip install datasets soundfile
```

## 当前优先级更新

1. 继续推进 Cambridge / ComParE 申请；
2. 如果拿不到 Cambridge，争取 CODA TB；

4. 避免使用 mixed-source COVID cough mirrors 作为主外部验证。

## 对当前论文路线的影响

当前 paper skeleton 不需要改主线。它已经写成 deployment failure audit。新增候选的意义是：

- Cambridge：加强同任务独立外部验证；
- CODA TB：加强跨疾病/跨任务 cough deployment reliability；
- FluSense：加强 respiratory event / representation robustness，但证据等级低于 Cambridge 和 CODA TB。
