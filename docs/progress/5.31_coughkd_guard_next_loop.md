# 2026-05-31 CoughKD-Guard: Next Loop Definition

## 1. Why the Previous Method-Search Loop Stopped

The A/B/C method candidates did not pass the gate. The controlled conclusion is not "we found a better distillation method", but:

> Existing compact cough KD variants can produce small, unstable gains in COUGHVID external validation, and several shortcut/domain-aware interventions fail to reliably improve external AUROC.

This negative result is useful only if we convert it into a sharper research question.

## 2. Current Candidate Claim

Working claim:

> **CoughKD-Guard** is a target-unlabeled pre-deployment audit for ultra-light cough distillation. It predicts whether a distilled student is likely to transfer safely to a new cough-audio target domain and selects a safer compact model before target labels are available.

This is not another KD loss. It is a deployment-time model-selection / risk-auditing protocol.

## 3. Why This May Be Novel Enough

The closest related directions found so far are:

| Related work type | Why it is close | Why our current idea is different |
|---|---|---|
| Coughprint 2025 | Distills cough representations into edge students | It focuses on representation distillation itself, not predicting KD negative transfer under target shift |
| OPERA / AcuLa / respiratory foundation models | Use large respiratory/audio-language models | They are foundation/zero-shot models, not compact KD transfer-risk guards |
| TRIAGE 2026 respiratory audio | Adaptive test-time scaling for zero-shot respiratory classification | It routes samples through reasoning tiers; we choose among compact student models before deployment |
| Triage KD 2026 speaker verification | Uses triage terminology inside KD training | It partitions posterior probabilities for speaker verification; our claim is target-unlabeled model selection under cough-audio domain shift |
| WAKD / ShiftKD / KD-under-shift benchmarks | Study KD under distribution shift | They are broad KD studies; the novelty must come from cough-audio deployment, unlabeled target signals, and negative-transfer prevention |

Current novelty status:

- Not yet proven.
- Plausible only if multi-target evidence shows that target-unlabeled signals predict or prevent KD negative transfer.

## 5. Next Automatic Experiment

### Required new evidence

Add a second external target. Earlier we considered DiCOVA, but this is not ideal as an independent target because the DiCOVA challenge dataset is derived from Coswara. If the current Coswara source split contains overlapping DiCOVA subjects, DiCOVA is not a clean external validation set.

Preferred target priority:

1. **ComParE 2021 COVID-19 Cough Sub-Challenge (CCS)** / Cambridge COVID-19 Sounds derived cough data, because it is not simply the same Coswara-derived split.
2. **DiCOVA Track-1** only if we can verify no subject overlap with the Coswara training split or rebuild the Coswara source split excluding DiCOVA subjects.
3. Another labeled cough COVID dataset with accessible audio and labels.

### New gate for CoughKD-Guard

Across COUGHVID + the second target:

1. The guard score must select a non-negative-transfer method on both targets.
2. The selected method must beat always-use-vanilla-KD in mean external macro AUROC.
3. Negative-transfer rate must be reduced by at least 30% compared with always-use-KD or always-use-best-source method.
4. A target-unlabeled signal must correlate with macro delta across method-seed-target points:
   - Pearson or Spearman >= 0.5
   - at least 15 points
5. No target labels are allowed in selection.

If these fail, stop CoughKD-Guard and return to literature search.
