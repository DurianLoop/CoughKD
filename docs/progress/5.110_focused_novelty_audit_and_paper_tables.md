## Focused literature collision audit

### COVID cough audio and metadata

Relevant sources:

- COUGHVID dataset paper: https://www.nature.com/articles/s41597-021-00937-4
- Multi-center cough validation with abundant metadata: https://www.sciencedirect.com/science/article/abs/pii/S1532046425000279
- SympCoughNet symptom-assisted COVID cough detection: https://pmc.ncbi.nlm.nih.gov/articles/PMC11936986/
- Drift-adaptive COVID cough detection: https://arxiv.org/abs/2409.19300
- Cross-dataset cough transfer / COVID cough work: https://arxiv.org/abs/2210.05843

What these cover:

- metadata and symptoms can be useful or confounding;
- cross-dataset COVID cough performance is fragile;
- symptoms can be injected into an audio classifier;
- dynamic/drift-aware adaptation is a real concern.

What they do not appear to claim:

- a deployment-time rule that classifies target metadata fields by semantic transfer safety;
- a router that allows symptom/acquisition slices to define slice gates while routing demographic-only slices to calibration stacking;
- negative-control evidence that flipping the metadata semantic rule collapses cross-target gains.

### Negative transfer and safe transfer

Relevant sources:

- Negative-transfer survey: https://www.ieee-jas.net/article/doi/10.1109/JAS.2022.106004
- ArXiv version of the negative-transfer survey: https://arxiv.org/abs/2009.00909
- Characterizing and avoiding negative transfer: https://arxiv.org/abs/1811.09751
- Partial transfer with selective adversarial networks: https://arxiv.org/abs/1707.07901

What these cover:

- negative transfer is well known;
- safe transfer can use domain similarity, source selection, or mitigation objectives;
- transfer strategy choice is not novel by itself.

What they do not appear to claim:

- cough-audio metadata-semantics-constrained routing between slice gating and stacking;
- target metadata field type as the primary safety prior for strategy selection;
- the specific symptom-vs-demographic semantic negative control used here.

### Semantic descriptors and domain adaptation

Relevant sources:

- Unified multi-domain/multi-task learning with zero-shot domain adaptation via semantic descriptors: https://arxiv.org/abs/1412.7489
- Zero-shot domain adaptation without domain semantic descriptors: https://arxiv.org/abs/1807.02927

What these cover:

- domain semantic descriptors can parameterize or infer domain-specific models;
- descriptors can be used for adaptation across domains.

What they do not appear to claim:

- deciding whether a metadata column is safe to use as a target slice gate;
- a conservative field-type whitelist separating symptom/acquisition metadata from demographic-only metadata;
- deployment routing among already-trained cough audio strategies.

### Respiratory foundation/stacking work

Relevant source:

- PulmoVec / HeAR stacking with metadata: https://arxiv.org/abs/2603.15688

What this covers:

- respiratory-sound foundation representations;
- stacking probability outputs with demographic metadata in a meta-model;
- multi-task respiratory sound classification.

What it does not appear to claim:

- metadata semantic safety constraints for transfer routing;
- negative controls showing demographic slice gates are unsafe while symptom/acquisition gates are useful.

## Novelty boundary

Do not claim novelty for:

- using metadata;
- using symptoms;
- using stacking;
- avoiding negative transfer;
- domain adaptation;
- target calibration;
- safe transfer in general.

The narrow claim that may remain novel is:

> In COVID cough transfer, target metadata fields should not be treated as interchangeable routing variables. A semantic safety prior over metadata type, distinguishing symptom/acquisition fields from demographic-only fields, can route between slice-gated transfer and calibration stacking; flipping this semantic prior collapses the gain.

This is a stronger and narrower claim than 5.108/5.109, but it is still not fully certified as "previously nobody has done it." It is now ready for deeper systematic literature review and paper drafting.

## Evidence status

Strong evidence:

- 1000-repeat mean gains are positive on COUGHVID and TosCOVID.
- Negative controls collapse the gains in the predicted direction.
- 30% calibration remains in the target improvement range.
- The result is cheap, reproducible from existing prediction CSVs, and does not depend on a new training sweep.

Weak evidence:

- only two large external targets;
- split-tail negative events remain;
- 10% calibration fails on COUGHVID;
- novelty not yet checked against every metadata-conditioned model-selection or safe-transfer paper.
