- Full TosCOVID 2021 local manifest has 5,794 audio rows.
- Official split rows:
  - train: 4,803 audio rows, 2,254 subjects
  - test: 991 audio rows, 495 subjects
- Existing prediction artifacts cover the official test split at 100% for the planned method/seed set.
- Existing prediction artifacts cover the official train split at 0%.
- `scripts/evaluate_external_model_set.py --dry-run` now emits 25 official-train inference commands, including `candidate_f_artifact_env_irm_ramp` seed7.

## Decision

Verdict: `NOT_READY_MISSING_OFFICIAL_TRAIN_PREDICTIONS`

This route is useful as a paper-rigor upgrade, not as a new third-target claim. It can separate TosCOVID calibration from final evaluation using the official split, but the next step needs explicit approval because it requires inference over 4,803 train audio rows for existing checkpoints/methods.

The downstream official-split semantic-router gate currently reports `NOT_READY_MISSING_OFFICIAL_SPLIT_PREDICTIONS`. After approval, run `scripts/run_toscovid_official_train_inference_windows.cmd`; it will generate train predictions and recompute:

- official-train best-single control
- official-train semantic router, which uses logistic stacking for TosCOVID because age metadata is demographic/nonsemantic
- delta vs source-only on official test
