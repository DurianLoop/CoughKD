# 5.105 Low-cost public external target re-scout

## Purpose

Before asking for a large UKCOVID download or gated HeAR access again, this note re-checks whether a lower-cost public external target can move the ICASSP 2027 positive-claim search.

No download or model training was run.

## Candidate assessment

| candidate | status | why it cannot replace UKCOVID/Cambridge/HeAR |
| --- | --- | --- |
| HF COUGHVID-style tasks | public, small | Mostly COUGHVID-derived; not independent from the current strongest target. |
| HF Coswara mirrors | public | Source-domain overlap risk; cannot be treated as independent external validation. |
| Processed mixed COVID cough sets | public/mirrored | Often mix Coswara/COUGHVID/Cambridge/Virufy; overlap and preprocessing leakage risk. |
| Virufy | already local/evaluated | Too small for main claim; useful only as stress evidence. |
| NoCoCoDa | small/request-oriented | Too small/noisy for a 3-5 point ICASSP external claim; not clearly better than existing Virufy stress target. |
| DiCOVA | challenge/registration | Coswara-related; useful only as auxiliary with overlap control. |
| CODA TB / non-COVID cough | access/reframe needed | Disease/task label differs; would change the paper from COVID cough to generic cough deployment reliability. |

## Decision

No low-cost public replacement was found.

The practical conclusion remains:

1. **For a positive external-validation claim:** UKCOVID audio or Cambridge access is required.
2. **For a new method mechanism:** HeAR/OPERA foundation embedding gate is required.
3. **Without either:** pivot to guarded-transfer/failure-slice audit instead of forcing a 3-5 point positive claim.

## Current stop rule

Do not spend more compute on local-only KD variants unless a new external state changes:

- UKCOVID/Cambridge audio becomes available; or
- HeAR/OPERA frozen embedding gate clears the TosCOVID signal threshold; or
- the paper objective is explicitly broadened away from COVID external diagnosis toward generic cough deployment reliability.

- approve UKCOVID audio download/extraction;
- provide/approve HeAR PyTorch gated weights;
