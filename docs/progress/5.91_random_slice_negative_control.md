# 5.91 Random Slice Negative Control

## Purpose

Stress-test the current best candidate:

> Is the margin-regularized `symptom_resp` slice gate genuinely using symptom metadata, or would any random binary split produce similar gains?

This is a negative control for the main local signal.

## Configuration

Target:

- COUGHVID

Real slice:

- `symptom_resp`

Gate:

- base method: `source_only`
- switch margin: `0.02`
- train fraction: `0.7`
- min train slice: `100`

Real repeats:

- `200`

Random controls:

- `30`
- each control is a random binary split matching the minority-slice count of `symptom_resp`
- each control is evaluated with the same gate and `200` repeats.

## Interpretation

This is strong supporting evidence for the candidate.

Positive:

- The real symptom slice gives mean `+4.59` points.
- Random matched binary slices average about `-0.15` points.
- None of the 30 random controls matched or exceeded the real-slice mean.
- The real slice has CI lower bound above `+2` points in this 200-repeat run.

What this rules out:

- The gain is unlikely to be explained by arbitrary binary partitioning alone.
- The symptom metadata appears to carry meaningful transfer-gating information.

What this does not prove:

- Cross-dataset robustness.
- Low-label/few-shot operation.
- Independence from COUGHVID-specific symptom annotation artifacts.

## Candidate Status

Current best candidate:

> Margin-regularized symptom-slice transfer gate.

Evidence strengthened:

- repeated held-out gains in the target 3-5 point range on COUGHVID,
- nested margin selection remains positive,
- random binary negative controls fail,
- clinically interpretable slice variable.

Still missing before a defensible ICASSP claim:

- replication on a second large external target,
- preferably UKCOVID because it has symptoms/demographics and many subjects,
- or improved representation evidence from HeAR/OPERA followed by the same gate.

## Decision

Keep this as the active main candidate.

Do not claim yet, because it remains COUGHVID-only. The next high-value action is external-state dependent:

1. obtain/run UKCOVID audio,
2. or obtain/run HeAR/OPERA foundation embeddings.
