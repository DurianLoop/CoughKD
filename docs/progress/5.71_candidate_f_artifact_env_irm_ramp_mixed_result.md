# 5.71 Candidate F Artifact-Env IRM Ramp Mixed Result

## Purpose

Continue after Candidate E failed by testing a representation-level route instead of another scalar KD weight.

Candidate F:

> Artifact pseudo-environment risk matching for ultra-light cough KD

The intended novelty boundary is narrow:

- no explicit source device labels are available;
- pseudo-environments are inferred from low-level recording artifact features;
- the intervention is a risk-matching regularizer during KD training, not sample-level KD gating and not domain-adversarial source-target alignment.

Related-work boundary checked in this round:

- Device-invariant respiratory classification already exists with explicit device information and adversarial/IRM-style learning: `https://www.nature.com/articles/s41746-026-02445-4`
- Environment inference for invariant learning is prior art: `https://arxiv.org/abs/2010.07249`

Therefore Candidate F is not claimable as generic IRM or generic device-invariant learning. It is only potentially claimable if the cough-specific, device-label-free artifact pseudo-environment route improves external cough transfer robustly.

- A sigmoid ramp is a principled schedule, not post-hoc threshold tuning.

## Decision

Candidate F-ramp is **not claimable**.

Reason:

- It is the first route in this loop to pass the COUGHVID continuation gate.
- But it fails Tos, even though Tos is the target with the strongest artifact-feature shift.
- Therefore the result is target-dependent, not a robust ICASSP method claim.

Do not expand this run to three seeds yet.

## Interpretation

Useful signals:

- Device-label-free artifact pseudo-environments are real enough to diagnose.
- A gentle early artifact-risk regularizer can improve COUGHVID over Candidate E and prior source-only references.

Failure signals:

- Tos failure means the main Tos shift is not solved by source-side artifact risk matching alone.
- The best checkpoint occurs while the effective env risk weight is still small, so the later strong IRM part is not earning the gain.
- This weakens any claim that invariant risk matching itself is the mechanism.

## Next Step

Do not tune `env-risk-weight` blindly.

Next round should inspect Tos-specific failure before another training run:

1. Compare source/COUGHVID/Tos artifact-feature distributions by class-agnostic slices.
2. Check whether Tos label mapping or binary target composition makes source five-class KD inappropriate.
3. Audit whether Candidate F improves COUGHVID by changing COVID ranking, healthy ranking, or only respiratory-illness ranking.
4. Read target-unlabeled cough/audio adaptation work before deciding whether a Tos-aware but label-free intervention is acceptable for the ICASSP claim.

Tentative direction:

- If we allow unlabeled target structure, test target-coverage-aware artifact alignment.
- If the claim must stay source-only, Candidate F should be treated as a useful partial result but not the final route.
