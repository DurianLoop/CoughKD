## Decision

HeAR PyTorch remains the best next route:

- health-acoustic,
- PyTorch-native,
- environment already ready,
- one gated asset step.

OPERA is second:

- respiratory-specific,
- but requires repo clone, dependency install, and likely checkpoint download.

No new KD method should be designed until HeAR or OPERA clears the frozen embedding gate.
