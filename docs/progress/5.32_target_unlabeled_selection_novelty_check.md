# 2026-05-32 Target-Unlabeled Selection Novelty Check

## 1. Why This Check Matters

CoughKD-Guard is only viable if it is not just a renamed version of existing unsupervised model selection or transferability estimation.

The broader machine-learning area already has many target-unlabeled model selection ideas:

- estimating target risk without target labels;
- source-free domain adaptation model selection;
- transferability / domain-similarity scoring;
- entropy / confidence / calibration based target risk proxies;
- adapting or selecting models using unlabeled target data.

Therefore, the novelty cannot be:

> We use unlabeled target data to select a model.

That is too broad and already studied.

## 2. Safer Novelty Boundary

The defensible novelty boundary should be narrower:

> We study ultra-light cough audio knowledge distillation under source-to-target dataset shift and introduce a target-unlabeled deployment guard that detects KD negative-transfer risk and chooses among compact CE/KD/adapted student checkpoints before deployment.

This boundary combines:

1. cough/respiratory audio;
2. ultra-light student deployment;
3. knowledge-distillation negative transfer;
4. target-unlabeled pre-deployment audit;
5. cross-dataset external evaluation.

If any of these are removed, the claim becomes much less novel.

## 3. Related Work Categories To Cite

### Generic unsupervised model selection / target risk estimation

These works reduce novelty for the broad idea of target-unlabeled model selection. We should cite them and position CoughKD-Guard as domain/task-specific.

Candidate search terms:

- `unsupervised model selection domain adaptation target risk`
- `source-free domain adaptation model selection`
- `transferability estimation source-free domain adaptation`
- `Deep Embedded Validation domain adaptation`
- `SUTE SEA unsupervised domain adaptation model selection`
- `Cal-SFDA source-free domain adaptation model selection`

### KD under distribution shift

These works reduce novelty for the broad claim that KD can fail under shift.

Examples already identified:

- WAKD / weight-averaged KD under domain shift.
- KD^3 / knowledge distillation between different distributions.
- Revisiting KD under distribution shift.
- ShiftKD.

### Respiratory foundation / adaptive inference

These works reduce novelty for large-model respiratory audio and adaptive routing:

- AcuLa

- TRIAGE adaptive test-time scaling
- Coughprint

## 4. What Would Make CoughKD-Guard Stand

CoughKD-Guard becomes a real contribution only if experiments show:

1. **Negative transfer is common**
   - Several KD variants hurt external macro AUROC compared with source-only / CE baselines.

2. **The guard uses no target labels**
   - Selection can use target audio and model predictions, but no ground truth.

3. **The guard has decision utility**
   - It avoids negative-transfer choices more often than always-use-KD.
   - It selects a method close to the best post-hoc method on multiple target domains.

4. **The finding is respiratory/cough specific**
   - The paper explains why confidence, predicted class prior, and entropy shift are meaningful in cough screening datasets with severe label/domain shift.

5. **The method is deployment-relevant**
   - The chosen model remains ultra-light; the guard does not require a large teacher at inference.

## 5. Current Status

Current evidence satisfies only part of this:

- COUGHVID shows 5/7 candidate methods have negative macro transfer relative to source-only.
- The current guard score selects `tcd_conf035`, which is also the best macro method on COUGHVID after labels are revealed.
- But this is one target only.

Missing:

- independent second target;
- multi-target correlation;
- proof that the guard is not overfit to COUGHVID;
- comparison against generic unsupervised model selection baselines such as entropy-only, confidence-only, and source-only selection.
