# 5.72 Tos Failure Label-Space Audit and Binary Diagnostic

## Purpose

Follow up Candidate F-ramp:

- COUGHVID passed the continuation gate.
- Tos COVID-19 failed badly.

This round asks whether the Tos failure is caused by label-space mismatch, subject aggregation, artifact environment slices, or something deeper.

## Related-Work Boundary

This is close to partial domain adaptation:

- Partial domain adaptation assumes the target label space is a subset of the source label space.
- Source-private classes can cause negative transfer.
- Existing PDA work already handles source-private class down-weighting and shared-class selection.

Useful references checked:

- Partial Adversarial Domain Adaptation, ECCV 2018: `https://www.ecva.net/papers/eccv_2018/papers_ECCV/html/Zhangjie_Cao_Partial_Adversarial_Domain_ECCV_2018_paper.php`
- Universal/partial/open-set label-set mismatch overview: `https://pmc.ncbi.nlm.nih.gov/articles/PMC8620052/`
- Shared-class oriented PDA: `https://www.sciencedirect.com/science/article/pii/S1077314220300795`

Therefore a future Candidate G cannot simply claim "partial domain adaptation." It must be cough-audio-specific and tied to ultra-light KD / external target auditing.

## Current Conclusion

Candidate G should **not** be a simple binary label-space remap.

The hard evidence now says:

- Tos env 1 is the failure slice.
- Source-private probability mass contributes to confusion, but projection and native binary training do not solve ranking.
- The key problem is likely a combination of target recording condition and target-specific disease/label semantics, not label space alone.

## Next Step

Do not train another model until one more diagnostic is complete:

1. Compare source vs Tos env-1 feature distribution against source train subclusters.
2. Check whether Tos env-1 positive/negative labels differ in artifact features at all; if they do not, no artifact-only method can rank COVID there.
3. If Tos env-1 label signal is weak in low-level artifact space, move away from artifact invariance and read cough-pathophysiology/foundation-feature papers.
4. If Tos env-1 has a separable target-unlabeled structure, consider a target-coverage-aware method, but it must be framed as target-unlabeled adaptation and compared against PDA prior art.

Recommended next candidate direction:

- Target env-slice separability audit first.
- Then either abandon Tos as a method-development target or design a target-unlabeled, env-slice-specific intervention.
