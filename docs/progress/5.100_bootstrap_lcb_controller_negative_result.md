# 5.100 Bootstrap-LCB controller negative result

## Purpose

5.99 showed that a target-calibrated controller can often choose the intuitive family:

- COUGHVID tends to need the symptom slice gate.
- TosCOVID tends to need logistic stacking.

However, inner-validation AUROC selection was too noisy. This note tests the next low-cost hypothesis:

> Select transfer strategies by a bootstrap lower confidence bound (LCB) of inner-validation AUROC delta versus source-only, instead of by the raw inner-validation mean.

The motivation is conservative negative-transfer control. The novelty boundary is narrow: bootstrap and confidence-bound model selection are broad existing ideas, while the cough/COVID audio literature found so far emphasizes external validation, dataset shift, confounding, domain adaptation, or metadata/symptom risk rather than a target-calibrated bootstrap-LCB transfer controller. This is therefore a candidate domain-specific guard, not a new statistical theory.

Relevant anchors:

- Cough/COVID audio external validation and drift risk remain central concerns: https://www.jmir.org/2025/1/e66919/
- Vocal audio COVID screening has documented confounding and dataset-shift risks: https://www.nature.com/articles/s42256-023-00773-8
- UKCOVID provides a large external-data route with symptom metadata, but local audio is still missing: https://www.nature.com/articles/s41597-024-03492-w

## Protocol

Targets:

- COUGHVID
- TosCOVID

Nested split:

1. Split target into outer calibration and held-out evaluation.
2. Split outer calibration into inner train and inner validation.
3. Fit each candidate strategy on inner train.
4. On inner validation, bootstrap the AUROC delta of each strategy versus source-only.
5. Select the strategy with the highest LCB delta; switch only if LCB >= 0.
6. Refit the selected strategy on full outer calibration.
7. Evaluate on outer held-out labels.

Settings:

- repeats: 80
- outer train fraction: 0.5
- inner train fraction: 0.7
- bootstrap samples: 80
- LCB alpha: 0.10
- LCB floor: 0.0
- stack C: 1.0

Candidate strategies:

- source-only
- calibration-best single model
- logistic stacking
- metadata slice gate

## Interpretation

This is a negative result.

Bootstrap-LCB selection makes the controller safer but too conservative:

- On COUGHVID, it still mostly selects the symptom slice gate, but the mean gain remains below 3 points and the confidence interval includes negative values.
- On TosCOVID, logistic stacking has a positive inner mean delta, but the bootstrap LCB is strongly negative. The controller therefore falls back to source-only in 55/80 repeats, collapsing the held-out mean gain to about +0.5 points.

Compared with 5.99, the LCB selector reduces adventurous switching rather than solving strategy reliability:

- 5.99 no-margin controller: COUGHVID +0.027915, TosCOVID +0.019482.
- 5.100 bootstrap-LCB controller: COUGHVID +0.026705, TosCOVID +0.005028.

## Claim status

Not claimable.

The result fails the ICASSP evidence gate because:

- neither large target clears a 3-point mean gain;
- TosCOVID collapses under conservative selection;
- confidence intervals still include negative values;
- the method is close to existing uncertainty-aware validation/model-selection ideas unless paired with a stronger cough-specific mechanism.

## Next implication

The controller route is now weak. Further tuning of selector thresholds is unlikely to produce a defensible ICASSP claim because the best available controller variants either:

- select too aggressively and remain noisy; or
- select conservatively and lose TosCOVID gains.

The next useful move should be one of:

1. A training-time mechanism that changes representations or objectives, not only post-hoc selection.
2. A second real external target with audio, especially UKCOVID or Cambridge, so the symptom-slice idea can be tested beyond COUGHVID.
3. A narrower paper angle around failure-aware external target auditing, if the goal shifts from 3-5 point improvement to methodological diagnosis.
