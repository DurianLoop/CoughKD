# 2026-05-28 Stage 3c Domain Probe 结果

## 1. 结论

Stage 3c 的 external evaluation 显示 TCD 相对 source-only 有稳定但很小的提升：

```text
tcd_very_strong: Δ macro AUROC +0.000495, Δ COVID AUROC +0.002702
tcd_conf035:     Δ macro AUROC +0.000701, Δ COVID AUROC +0.002161
```

但是 domain/task probe 不支持“目标域一致性改善了表征”的强 claim：

```text
tcd_very_strong: domain AUC 平均 +0.002374, task AUC 平均 -0.001030
tcd_conf035:     domain AUC 平均 +0.001791, task AUC 平均 -0.001090
```

也就是说：

> TCD 在 COUGHVID external ranking 上有稳定小收益，但没有减少 domain-identifiable representation，也没有提升 task-readable representation。

因此，TCD 不能作为 AAAI 级别强方法主 claim。它可以作为分析型论文中的一个正向但有限的 ablation。

## 4. 当前判断

当前实验链路已经说明：

1. **SA-KD / sample weighting 不成立**  
   in-domain 上升，但 external 下降，domain probe 变差。

2. **TCD / target consistency 有弱正外部收益**  
   external macro AUROC 与 COVID AUROC 稳定略高于 source-only。

3. **TCD 不能说明表征更 domain-invariant**  
   domain probe AUC 相对 source-only 略升。

4. **TCD 不能说明任务表征明显更强**  
   task probe AUC 相对 source-only 略降。

所以现在不建议继续堆 TCD 变体。继续调 target weight、threshold、mask ratio 很可能只是工程调参。

## 5. 下一步建议

下一步应从“发明一个强方法”转为“做扎实的分析型研究”：

> **When Does Knowledge Distillation Help or Fail for Ultra-Light Cough Audio Models under Dataset Shift?**

需要补的是更严谨的独立 seed，而不是更多方法变体。

最低成本下一步：

1. 独立跑 seeds `11, 23` 的 PANNs teacher / CE student / vanilla KD；
2. 对每个 seed 做 COUGHVID-test external；
3. 对每个 seed 做 domain/task probe；
4. 汇总 CE vs KD vs source-only vs TCD 的 mean ± std。

如果独立 seeds 下 vanilla KD 本身也不稳定，则论文主线应该转为：

> in-domain KD gains do not reliably translate into external cough-dataset generalization.

如果 vanilla KD 稳定，而 TCD 只有微弱提升，则可以把 TCD 写成 limited mitigation，而不是主贡献。
