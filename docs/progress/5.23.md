# 2026-05-23 Stage 2 实验计划实现记录

## 1. 本次实现目标

根据 `SHORTCUT_AUDITED_COUGHKD_PLAN.md`，本次把 Stage 2 从“方法设想”推进为可运行代码：

```text
teacher/student shortcut audit
-> sample-level shortcut risk
-> shortcut-weighted KD
-> external/test + domain probe 验证
```

核心思想是：不再让 student 无差别模仿 teacher，而是为每个训练样本计算 `kd_weight`。当样本更可能携带录音质量、数据集来源、扰动不稳定等 shortcut 风险时，降低 KD 项强度；真实标签 CE 仍保留。

训练目标实现为：

```text
L = L_CE
  + lambda_response * w(x) * L_responseKD
  + lambda_feature  * w(x) * L_featureKD
  + lambda_embedding * w(x) * L_embeddingKD
  + lambda_relation * mean(w) * L_relationKD
```

其中 `w(x)` 来自 `shortcut_weights.csv` 的 `kd_weight`。

## 2. 新增和修改的文件

### 2.1 新增脚本

```text
scripts/build_shortcut_weights.py
```

作用：为 Coswara train split 生成 sample-level KD 权重。

当前支持三类风险/权重：

1. **Audio quality weight**
   - duration
   - RMS / log RMS
   - clipping fraction
   - silence ratio
   - peak
   - zero-crossing rate
   - cough_detected

2. **Domain risk weight**
   - 使用 Coswara train 与 COUGHVID adapt 的音频统计特征训练 domain probe；
   - 如果某个 Coswara 样本被 probe 高置信判定为 source-typical，则认为它更可能带有 dataset-specific shortcut；
   - domain-specific 越强，`domain_weight` 越低。

3. **Augmentation stability weight**
   - 读取已有 student checkpoint；
   - 对同一音频做 gain/noise/time-shift；
   - 计算原始预测与扰动预测之间的 Jensen-Shannon divergence；
   - 扰动后预测越不稳定，`stability_weight` 越低。

输出：

```text
shortcut_weights.csv
shortcut_weight_summary.json
SHORTCUT_WEIGHTS.md
```

核心列：

```text
recording_id, quality_weight, domain_weight, stability_weight, kd_weight
```

### 2.2 新增一键 Stage 2 脚本

```text
scripts/run_shortcut_audited_stage2_windows.cmd
```

作用：在 Windows + conda 环境下按顺序运行：

1. full shortcut weights；
2. quality-only SA-KD；
3. domain-risk-only SA-KD；
4. full SA-KD；
5. COUGHVID-test external evaluation；
6. Coswara vs COUGHVID domain probe；
7. 输出结果路径。

### 2.3 修改训练代码

```text
src/coughkd/torch_models.py
src/coughkd/cli.py
```

新增能力：

- `CoughManifestDataset` 支持根据 `recording_id` 返回 `kd_weight`；
- `pad_collate` 会把 batch 内 `kd_weight` 拼成 tensor；
- `torch_kd_loss` 支持按样本加权 KD loss；
- `torch-train` 新增参数：

```text
--kd-sample-weights PATH
--init-teacher-checkpoint PATH
```

`--init-teacher-checkpoint` 用来固定已训练 teacher，避免 Stage 2 每个 KD 变体重新训练 teacher，从而减少实验混杂和时间消耗。

## 5. 第一轮正式结果要看什么

不要只看 in-domain AUROC。第一轮重点看：

1. `stage2_sakd_*` 在 Coswara test 是否不明显低于 vanilla KD；
2. `external_coughvid_test_stage2_sakd_*` 是否比 vanilla KD/CE 的 COUGHVID-test AUROC 更稳；
3. `domain_probe_stage2_sakd_seed7` 里 SA-KD 的 domain probe AUC 是否低于 vanilla KD；
4. task probe AUC 是否没有明显损失；
5. full SA-KD 是否比 quality-only/domain-only 更好。

如果 full SA-KD 同时满足：

```text
external AUROC >= vanilla KD
domain probe AUC < vanilla KD
task probe AUC roughly preserved
```

那么这个方向可以继续扩展到 3 seeds。

如果 full SA-KD 只降低 domain AUC 但也损失 external AUROC，说明当前权重过强，需要调高 `--floor` 或降低 `domain-power/stability-power`。

如果 domain AUC 不变但 external AUROC 提升，说明 shortcut audit 可能主要起到了 regularization 作用，仍然可以写，但表述要谨慎。
