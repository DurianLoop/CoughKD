# 5.141 UKCOVID Download-Verify Driver

Date: 2026-06-09

## Purpose

The UKCOVID route now has preflight and archive checksum gates. I added a
single approval-time Windows driver that chains the safe download workflow:

1. no-download preflight;
2. preflight verdict check;
3. resumable split-archive download;
4. size/checksum verifier;
5. `READY_FOR_EXTRACTION` verdict check;
6. handoff to manual extraction and the post-audio semantic-router driver.

## New script

- `scripts/run_ukcovid_audio_download_verify_windows.cmd`

The script supports:

```cmd
scripts\run_ukcovid_audio_download_verify_windows.cmd --dry-run
```

The dry run prints commands only and does not download data.

## Integration

- `UKCOVID_SEMANTIC_ROUTER_EXECUTION_PACK.md` now recommends the new driver.
- Submission readiness requires the driver to be present.
- Claim dossier checks the execution pack for the driver and dry-run path.
