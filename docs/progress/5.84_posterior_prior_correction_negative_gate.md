# 5.84 Posterior Prior-Correction Negative Gate

## Purpose

Test one more no-download method component:

> Can target-unlabeled posterior/prior correction rescue external AUROC enough to become part of a 3-5 point ICASSP method?

This is a cheap approximation to label-shift correction. Full BBSE was not possible from current local assets because source-domain per-example validation predictions are not present.

## Literature Boundary

This direction is not novel by itself.

Prior/probability-shift correction is old and well established:

- Saerens, Latinne, and Decaestecker adjusted classifier outputs to new class priors in 2002.
- Lipton, Wang, and Smola proposed Black Box Shift Estimation for label shift in ICML 2018.
- Later work provides unified views and extensions of label-shift estimation.

Useful anchors:

- `https://pubmed.ncbi.nlm.nih.gov/11747533/`
- `https://proceedings.mlr.press/v80/lipton18a.html`
- `https://arxiv.org/abs/2003.07554`

Therefore, posterior/prior correction can only be a support component if it yields a strong empirical effect.

## Tested Corrections

The audit tested deterministic target-unlabeled posterior transforms:

- temperature sharpening/flattening,
- target mean-probability balancing,
- source-prior pull,
- COVID binary projection heuristics.

All transforms preserve the no-label target-time constraint. Labels are used only for post-hoc audit.

## Decision

Posterior/prior correction is not a claimable main route.

Reasons:

- On COUGHVID and TosCOVID, the largest gain is less than `+0.5` points.
- The only large gain is on the 16-example Virufy target.
- The method class is already covered by prior/label-shift literature.
- Full BBSE would require source validation predictions; even if implemented later, the current approximate gate gives no evidence that label shift is the missing 3-5 point mechanism.

Keep this as a negative gate and, at most, as a calibration appendix.
