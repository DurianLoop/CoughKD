## Literature Boundary Update

Recent checks reinforce the over-claim risk:

- Coughprint, IEEE TIM 2025, already covers cough representation distillation from speech foundation embeddings: `https://colab.ws/articles/10.1109%2Ftim.2025.3568985`
- Interspeech 2025 respiratory KD already covers architecture-agnostic ensemble soft-label distillation for respiratory sounds: `https://arxiv.org/abs/2505.22027`
- CoughSense, arXiv 2026, aggregates Coswara, CoughVID, Virufy, and pediatric cough data with a Whisper encoder for multi-class respiratory disease classification: `https://arxiv.org/abs/2606.02998`
- Older Virufy literature notes that Virufy is small and crowdsourced, so it is useful as a stress target but weak as a standalone proof target: `https://arxiv.org/abs/2011.13320`

Therefore the existing Virufy/Virufyseg gains cannot be framed as a broad cough foundation/distillation first.

## Decision

No existing external result currently satisfies the requested standard:

- 3-5 point gain,
- robust across seeds,
- on a sufficiently sized external target,
- with a novelty boundary not already occupied by Coughprint / respiratory KD / foundation respiratory models.

The strongest current positive evidence is:

- Virufyseg clip-level KD mean delta: `+0.051465`
- Virufyseg subject-level candidate_c mean delta: `+0.089947`

But both are too target-limited to become the main ICASSP 2027 innovation claim.

## Implication

Do not pivot the paper to a Virufy-only positive method claim.

The viable next actions remain:

1. **If the user approves gated model access:** test HeAR PyTorch frozen embeddings on Tos env1.
2. **If no new assets are approved:** continue developing a guarded-transfer/failure-slice paper, where Virufyseg is an auxiliary example of evaluation-unit sensitivity rather than a main performance claim.
3. **If new external data can be onboarded:** prioritize a larger second target where a 3-5 point gain can be tested with enough examples.
