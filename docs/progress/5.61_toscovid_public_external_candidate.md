# 5.61 Tos COVID-19 public external candidate

## 当前判断

为了补齐 CoughKD-ShiftAudit 的第二外部目标，本轮新增 Buenos Aires 开放数据集 **Tos COVID-19** 作为快速候选。它的价值在于：

- 与 Coswara/COUGHVID 来源独立；
- 标签来自 RT-PCR 检测结果，元数据说明为检测前后最多 3 天内采集；
- 官方提供 `train/test` subset；
- 2021 音频 ZIP 约 60MB，可比 UK COVID-19 Vocal Audio 的 50GiB 音频更快进入闭环。

该数据集不用于支持“临床诊断有效”结论，只用于外部数据集漂移下的 deployment audit。

## 数据源

- Dataset page: `https://data.buenosaires.gob.ar/dataset/tos-covid-19`
- CKAN API: `https://data.buenosaires.gob.ar/api/3/action/package_show?id=tos-covid-19`
- 2021 metadata: `https://cdn.buenosaires.gob.ar/datosabiertos/datasets/ministerio-de-salud/tos-covid-19/tos-covid-19.csv`
- 2021 audio ZIP: `https://cdn.buenosaires.gob.ar/datosabiertos/datasets/ministerio-de-salud/tos-covid-19/tos-covid-19.zip`
- 2022 metadata/audio also exist, but the 2022 CSV schema is not identical to the 2021 metadata schema, so it is not mixed into the first formal external run.

## 对论文路线的意义

如果 Tos 评估完成，当前 “second external target” blocker 可以被显著缓解。预期论文表述应更新为：

> We audit ultra-light cough audio distillation across COUGHVID and Tos COVID-19 as independent public external targets, with UK COVID-19 Vocal Audio prepared as a larger PCR-referenced target pending audio download.

若 Tos 结果与 COUGHVID 一致地显示 KD/TCD 收益极小，则它会增强分析型论文主线：

> existing response/target-consistency distillation provides limited and unstable gains for ultra-light cough students under independent dataset shift.

若 Tos 上出现明显相反结果，则需要进一步做 label distribution、audio format、recording condition 和 calibration shift 分析，不能立即宣称方法成功。
