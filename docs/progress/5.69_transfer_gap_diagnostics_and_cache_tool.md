# 5.69 Transfer-Gap Diagnostics and Cache Tool

## Purpose

Continue the innovation loop after Candidate D failed. Candidate E is still only a candidate:

> Transfer-Gap Audited KD (TGA-KD)

This round does not train a new method. It checks whether existing evidence supports a transfer-gap route and adds the missing cache tool needed before any loss design.

## Literature Boundary

Nearby work prevents a simple claim:

- Dataset-quality-for-KD work already studies what makes a good distillation dataset.
- Transfer-gap KD already exists in general settings.
- Entropy/adaptive/uncertainty KD already exists.

Therefore Candidate E cannot be a plain confidence/entropy weighting method. It must be cough-shift-specific, ultra-light-student-specific, and externally validated on COUGHVID/Tos without target-label tuning.

## Decision

Candidate E is **not ready for training** yet.

Reason:

- Existing source-test diagnostics show the phenomenon but are too small and post-hoc for source weighting.
- Source-train gap cache is now implemented but only smoke-tested.
- A loss should not be designed until full source-train gap is cached and audited.

Updated decision:

Candidate E is worth one more diagnostic step, but not yet a training loss.

Next diagnostic should build a source weighting table with several non-claim candidate signals and audit their distribution:

- class-balanced teacher reliability;
- margin floor / entropy cap;
- avoid overtrusting teacher responses in weak teacher classes;
- preserve coverage for minority classes rather than suppressing them.

Only if these weights are non-degenerate and materially different from Candidate D should they enter a seed-7 hard gate.
