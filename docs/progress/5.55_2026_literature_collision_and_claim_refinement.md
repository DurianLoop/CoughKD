# 5.55 2025/2026 Literature Collision Check and Claim Refinement

日期：2026-06-01

## 本轮目的

继续 `/goal` 自动推进时，不能只靠已有想法反复跑实验。要先确认：我们想 claim 的内容是否已经被 2025/2026 的相关论文占据。如果已经被占据，就收窄到更安全、更可审稿防守的贡献。

本轮重新检索了 2025/2026 附近的 cough audio、respiratory audio、KD under distribution shift、edge cough representation 相关工作。结论是：方法创新边界比之前更窄，但 ShiftAudit 分析型路线更稳。

## 新增/重新确认的关键撞车论文

### 1. DNDT/DNDF cross-dataset COVID cough evaluation, Expert Systems with Applications 2026

链接：

- https://www.sciencedirect.com/science/article/pii/S0957417426001491

关键信息：

- 2026 Expert Systems with Applications。
- 题目是 *Robust COVID-19 detection from cough sounds using deep neural decision tree and forest: A comprehensive cross-datasets evaluation*。
- 使用 Cambridge asymptomatic/symptomatic、Coswara、COUGHVID、Virufy、Virufy+NoCoCoDa 等五类/多类数据集。
- 报告了很高的 AUC/precision，并强调 cross-datasets analysis、demographic/geographic differences。

对我们的影响：

不能 claim：

- first comprehensive cross-dataset COVID cough evaluation；
- first to show multiple cough datasets matter；
- first COVID cough model with Virufy/Coswara/COUGHVID/Cambridge-style evaluation；
- SOTA COVID cough classification unless严格复现其协议并公平比较。

还能 claim：

- 我们不做 COVID diagnosis SOTA，而是审计 ultra-light student KD 在外部迁移时是否可靠；
- 我们的主证据不是高 AUC，而是 KD method ranking、calibration、probe、slice/bootstrap、evaluation unit 和 latency 之间的不一致；
- DNDT/DNDF 可以作为“强 COVID cough classifier 相关工作”，但不是 deployment KD failure audit。

### 2. CoughViT, ISWC/arXiv 2025

链接：

- https://arxiv.org/abs/2508.03764

关键信息：

- 题目是 *CoughViT: A Self-Supervised Vision Transformer for Cough Audio Representation Learning*。
- 作者 Justin Luong, Hao Xue, Flora D. Salim。
- 使用 masked data modelling 做 self-supervised cough representation learning。
- 在三个 cough classification downstream tasks 上比较预训练策略。

对我们的影响：

不能 claim：

- first cough audio representation learning framework；
- first self-supervised cough representation；
- first to address label scarcity in cough tasks。

还能 claim：

- 我们不提出新的 cough representation encoder，而是审计大 teacher 到 ultra-light student 的跨数据集蒸馏可靠性；
- CoughViT 如果后续可用，可以作为 teacher/feature extractor baseline，但不应变成新的无边界 teacher 搜索。

### 3. Coughprint, IEEE TIM 2025

链接：

- https://colab.ws/articles/10.1109%2Ftim.2025.3568985
- https://ieeexplore.ieee.org/document/11024165/

关键信息：

- 题目是 *Coughprint: Distilled Cough Representations From Speech Foundation Model Embeddings*。
- 明确做了从 speech foundation model embeddings 到 edge-compute student 的 cough representation distillation。
- 下游包括 cough/noncough、人声分类、cougher verification/identification、wet/dry cough 等。

对我们的影响：

不能 claim：

- first cough representation distillation；
- first edge cough student；
- first foundation-to-student cough representation compression。

还能 claim：

- 我们研究的是 disease-screening-like cross-dataset cough transfer 下，KD 是否会稳定帮助；
- 我们不只看 student 是否保留 teacher 表征，而是看 under shift 时外部 AUROC、calibration、domain/task probe、slice/bootstrap 和 evaluation unit 是否给出一致结论。

### 4. ShiftKD, Neural Networks 2025

链接：

- https://www.sciencedirect.com/science/article/pii/S089360802500718X
- https://pubmed.ncbi.nlm.nih.gov/40714475/

关键信息：

- 题目是 *ShiftKD: Benchmarking knowledge distillation under distribution shift*。
- Neural Networks 2025。
- 作者 Songming Zhang, Yuxiao Luo, Ziyu Lyu, Xiaofeng Chen。
- 评估 30+ KD 方法，覆盖 diversity/correlation shift 等通用 distribution shift。

对我们的影响：

不能 claim：

- first KD under distribution shift；
- first systematic KD failure benchmark；
- first to show KD may fail under shift。

还能 claim：

- 我们把这个问题落在 cough audio deployment 上，尤其是 external cough datasets、calibration、domain/task probes、slice/bootstrap target composition sensitivity 和 model efficiency 的联合证据；
- 我们不是通用 benchmark，而是 respiratory/cough deployment audit。

## 由此导出的实验策略

当前不应该继续新增 teacher/student/KD 方法，而应该固定 bounded audit protocol：

1. 保留现有方法集合：CE-only、vanilla KD、source-only、TCD、shortcut-suppressed、disagreement-gated、probe-adversarial。
2. 第二外部目标优先 Cambridge；如果不可得，CODA TB 用作 disease/task shift，DiCOVA 仅作 auxiliary protocol。
3. 新目标接入后只跑已有 checkpoints 和现有 audit pipeline，不重新发明方法。
4. 若第二目标复现弱收益/不稳定排名/指标冲突，论文写 ShiftAudit。
5. 若某一方法在 COUGHVID + 第二目标上稳定显著胜出，再转回方法 claim，但必须与 ShiftKD/Coughprint/respiratory KD 明确区分。

## 论文写法变化

Related work 中需要新增两类对照：

- DNDT/DNDF 2026 作为 COVID cough cross-dataset SOTA-style classifier 对照；
- CoughViT/Coughprint/OPERA 作为 cough/respiratory representation learning 对照。

Introduction 中应更明确：

> Our contribution is not another COVID cough classifier nor another cough representation learner. Instead, we audit whether compressing large audio knowledge into an ultra-light cough student remains reliable when the deployment target changes.

## 当前结论

这次检索没有发现已经完全覆盖 “ultra-light cough KD deployment failure cartography” 的论文，但发现了多个会压缩创新边界的工作。因此当前最稳路线仍然是：

> CoughKD-ShiftAudit = bounded, multi-evidence deployment audit for ultra-light cough audio distillation under external dataset shift.

它的成败不取决于能否发明一个新 KD loss，而取决于第二外部目标能否支持“KD under cough dataset shift 需要 failure audit”的论点。
