# 5.38 COUGHVID Bootstrap Target-Subset Stability

## 目的

25-slice stress test 仍然依赖人工定义 slice。本轮加入 bootstrap target-subset stress test：

> 从 COUGHVID test set 中随机抽取多个目标子集，用已有 predictions 计算各方法在不同目标组成下的 macro AUROC delta，检查方法 ranking 是否稳定。

注意：

- 这不是 label-free selector；
- 标签只在抽样后用于 audit metric；
- 目的是支持 CoughKD-FailBench 的 failure cartography。

## 新增脚本

- `scripts/bootstrap_coughvid_method_stability.py`
- 更新 `scripts/plot_kd_failure_analysis.py`，增加 `bootstrap_delta_distribution` 图。

运行：

```powershell
cd D:\CoughKD\AAAI
D:\conda\envs\CoughKD\python.exe scripts\bootstrap_coughvid_method_stability.py --subsets 200 --subset-size 800
D:\conda\envs\CoughKD\python.exe scripts\plot_kd_failure_analysis.py
```

## 结果

设置：

- subsets: 200
- subset size: 800

| Method | Mean delta vs source-only | Std | Positive rate | Negative rate | Best post-hoc rate |

| ce | -0.004260 | 0.015493 | 0.420000 | 0.580000 | 0.140000 |

| candidate_c | -0.001764 | 0.010637 | 0.415000 | 0.585000 | 0.115000 |

## 解释

### 1. `tcd_conf035` 是稳定但弱的收益

`tcd_conf035` 的 positive rate 为 `0.74`，mean delta 为 `+0.000823`，std 只有 `0.001424`。

这说明它确实比 vanilla KD 更稳定，但收益极小，不能作为强方法 claim。

### 2. Candidate A/B/C 有较大方差

Candidate A/B 的 std 大约 `0.016`，说明它们对目标子集组成很敏感。它们可能在某些 target subsets 上表现很好，但总体均值为负。

这支持一个重要的分析点：

> shortcut-aware 或 disagreement-aware 的策略可能带来局部收益，但在目标分布变化下并不稳定。

### 3. Post-hoc best 分散

best-posthoc rate 最高的是 `tcd_conf035`，但也只有 `0.215`。CE、candidate A/B/C 也会在一部分 bootstrap subsets 中成为最优。

这说明：

> 没有单一 KD 方法在所有目标子分布上占优；只报告整体 COUGHVID 均值会掩盖 target composition sensitivity。

## 对 claim 的作用

这轮结果进一步支持 **CoughKD-FailBench**：

可以写：

> Across 200 bootstrap target subsets, method rankings are unstable: the most stable KD variant has only a tiny mean gain, while shortcut-aware variants show large target-composition sensitivity. This suggests that ultra-light cough KD should be evaluated with target-subset stress tests rather than a single aggregate external AUROC.

不能写：

> Our method robustly improves all target subsets.
