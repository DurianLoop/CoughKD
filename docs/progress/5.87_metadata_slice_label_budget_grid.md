## Interpretation

This is the strongest local no-download result so far:

- COUGHVID `symptom_resp` at 70% calibration reaches mean `+3.10` points and median `+3.25` points.
- The improvement has a clinically interpretable gate:
  - respiratory-condition negative slice tends to use Candidate B,
  - respiratory-condition positive slice tends to use Candidate F.

But it is still not publication-ready:

- CI lower bound remains negative.
- `47.6%` of repeats are below the 3-point threshold.
- It uses 70% target calibration labels, which is a fairly expensive label budget.
- TosCOVID does not replicate the 3-point gain.
- Symptom/metadata-assisted cough classification already exists, so the novelty must be framed as negative-transfer gating, not metadata fusion.

## Current Best Candidate

Name:

> Label-efficient metadata-slice transfer gate.

Potential claim shape:

> A small number of target calibration labels can learn an interpretable symptom-conditioned gate that controls negative transfer across cough-COVID external shifts.

Current evidence:

- promising on COUGHVID,
- not stable enough,
- not reproduced on TosCOVID,
- requires larger external validation or stronger representations.

## Decision

Do not claim yet.

This is now the best local candidate to carry forward, but the honest next step is external-state dependent:

1. **UKCOVID audio**: best test of whether symptom/demographic slice gating stabilizes at large scale.
2. **HeAR/OPERA foundation gate**: best route to increase slice-specific model separability and push held-out gains beyond 3 points.
