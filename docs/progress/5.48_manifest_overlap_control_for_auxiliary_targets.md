# 5.48 Manifest Overlap Control for Auxiliary Targets

## 为什么要做

当前最需要补的是第二外部目标。但 DiCOVA 和 Coswara 有关联，如果直接把 DiCOVA 写成 independent external validation，会被审稿人质疑数据重叠。因此本轮实现一个通用 overlap-control 审计脚本，作为所有新 target 接入前的 mandatory gate。

## 新增脚本

```text
scripts/audit_manifest_overlap.py
```

检查内容：

- exact `recording_id` overlap；
- exact `subject_id` overlap；
- exact manifest `path` overlap；
- audio path stem overlap；
- path tail-2 / tail-3 overlap；
- recording_id / subject_id / path 中长度大于等于 6 的 token overlap；
- 可选 `--enable-hash` 的 SHA-256 文件哈希 overlap。

## Smoke audit

使用 Coswara source manifest 对 Virufy original 和 Virufy segmented 做快速重叠检查。

命令：

```powershell
cd D:\CoughKD\AAAI
D:\conda\envs\CoughKD\python.exe scripts\audit_manifest_overlap.py `
  --source-manifest manifests\coswara_cough.csv `
  --target-manifest manifests\virufy_external.csv `
  --out runs\overlap_audit\coswara_vs_virufy

D:\conda\envs\CoughKD\python.exe scripts\audit_manifest_overlap.py `
  --source-manifest manifests\coswara_cough.csv `
  --target-manifest manifests\virufy_segmented_external.csv `
  --out runs\overlap_audit\coswara_vs_virufyseg
```

结果：

| Target | Source rows | Target rows | Matches | Verdict |
|---|---:|---:|---:|---|
| Virufy original | 5491 | 16 | 0 | no_overlap_detected_by_configured_checks |
| Virufy segmented | 5491 | 121 | 0 | no_overlap_detected_by_configured_checks |

输出：

- `runs/overlap_audit/coswara_vs_virufy/OVERLAP_AUDIT.md`
- `runs/overlap_audit/coswara_vs_virufyseg/OVERLAP_AUDIT.md`

## 对 DiCOVA 的意义

如果后续拿到 DiCOVA，必须先构建 `manifests/dicova_external.csv`，然后运行：

```powershell
D:\conda\envs\CoughKD\python.exe scripts\audit_manifest_overlap.py `
  --source-manifest manifests\coswara_cough.csv `
  --target-manifest manifests\dicova_external.csv `
  --out runs\overlap_audit\coswara_vs_dicova
```

如果本地音频完整，进一步运行：

```powershell
D:\conda\envs\CoughKD\python.exe scripts\audit_manifest_overlap.py `
  --source-manifest manifests\coswara_cough.csv `
  --target-manifest manifests\dicova_external.csv `
  --out runs\overlap_audit\coswara_vs_dicova_hash `
  --enable-hash
```

如果发现 overlap，则不能把 DiCOVA 写成独立外部集，只能：

1. 去除 overlap 后报告；或
2. 明确写成 Coswara-derived auxiliary protocol；或
3. 放入 appendix，不作为主 claim 证据。

## 当前判断

这个脚本不直接增加模型性能，但增加论文可信度。它把“DiCOVA 不能当独立外部验证”的口头 caveat 变成了可执行审计步骤，对 ICASSP 审稿更重要。
