# 5.136 Latest Metadata/Text/Foundation Collision Sweep

Date: 2026-06-09

## Purpose

Continue the novelty-hardening loop without large downloads or new model runs.
This pass checks whether recent metadata-as-text, multimodal respiratory, and
metadata-gated audio work directly collides with the semantic-router claim.

Current claim under audit:

> Target metadata semantics can act as a safety prior for moderate-label
> transfer routing under cough dataset shift.

## Sources checked

- GLoRIA, arXiv:2603.02464 / ICASSP 2026: metadata-gated low-rank adaptation for
  dialectal ASR using location metadata.
- CoughSense, arXiv:2606.02998: Whisper/OPERA cough classification with symptom
  conditioning, domain adaptation, and multi-dataset respiratory disease
  classification.
- TIAMO, Expert Systems with Applications 2026: text-image-audio multimodal
  respiratory sound classification using LLM-generated text from patient
  metadata.
- BTS, arXiv:2406.06786 / Interspeech 2024: text/sound modalities for
  metadata-aided respiratory sound classification.
- RespiraMFM, OpenReview 2026 record: multimodal foundation model with
  contrastive audio-language alignment for respiratory disease identification,
  using metadata associated with respiratory sounds.

## Collision assessment

No direct collision was found for the current unit of novelty:

> a deployment router that treats target metadata fields as non-interchangeable
> transfer variables, allowing symptom/acquisition fields to support slice
> gates while routing demographic-only fields to calibration stacking, with
> inverted/all-slice/no-slice semantic controls.

Close but non-colliding areas:

- metadata-gated representation adaptation (GLoRIA);
- symptom-conditioned multi-dataset cough classification (CoughSense);
- metadata-as-text respiratory classification (TIAMO, BTS);
- multimodal respiratory foundation modeling (RespiraMFM);
- demographic metadata stacking and patient-context fusion.

Boundary impact:

- do not claim first metadata-gated audio adaptation;
- do not claim first symptom-conditioned cough model;
- do not claim first metadata-to-text respiratory model;
- do not claim first multimodal respiratory foundation model;
- keep the remaining contribution at the strategy-routing level.
