# 5.86 Metadata Slice Oracle and Crossfit Gate

## Purpose

Test whether metadata-conditioned method selection has enough upper-bound signal to justify a new method search.

Question:

> If we choose a different existing model per metadata slice, can we reach a 3-5 point gain on large external targets?

This is a stronger upper-bound check than global method selection because it allows a mixture-of-experts policy over demographic, symptom, and recording-quality slices.

## Literature Boundary

This idea is not free novelty.

Recent and prior work already uses symptoms, metadata, or ensemble/conglomerated models in cough/COVID audio:

- SympCoughNet uses symptom-assisted audio-based COVID-19 detection.
- COUGHVID and MIT Open Voice style datasets include symptoms/demographics alongside cough audio.
- Recent cough classification papers study hybrid/conglomerated model selection and metadata-aware respiratory disease classification.

Useful anchors:

- `https://pmc.ncbi.nlm.nih.gov/articles/PMC11936986/`
- `https://www.mdpi.com/1999-4893/17/7/302`
- `https://pmc.ncbi.nlm.nih.gov/articles/PMC8222356/`
- `https://pmc.ncbi.nlm.nih.gov/articles/PMC8545024/`

Therefore, a claim would need to be more specific:

> label-efficient, metadata-slice-conditioned transfer gating for negative-transfer control under external cough dataset shift.

## Crossfit Policy Check

1. randomly splits the target in half,
2. learns the best method per slice on the calibration half,
3. evaluates the learned policy on the held-out half.

## Decision

This is the closest local no-download signal so far, but it is still not a claimable ICASSP 2027 innovation.

Positive:

- COUGHVID symptom-conditioned oracle clears the 3-point gate.
- The selected slices are clinically interpretable: respiratory-condition metadata separates where Candidate B vs Candidate F is better.
- The idea aligns with the broader guarded-transfer/failure-slice direction.

Negative:

- Held-out crossfit mean on COUGHVID is only `+2.41` points, below the requested 3-point threshold.
- Crossfit CI lower bounds are negative for both COUGHVID and TosCOVID.
- TosCOVID oracle does not clear 3 points.
- Symptom/metadata-assisted cough audio classification already exists, so novelty would need a sharper negative-transfer framing.

Keep this as the strongest local follow-up candidate:

> Label-efficient metadata-slice transfer gate.

But do not claim it yet. It needs either:

- UKCOVID audio to test whether the same symptom/demographic gate becomes stable at large scale, or
- stronger foundation representations such as HeAR/OPERA to raise the slice-specific gains above 3 points.
