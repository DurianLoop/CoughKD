# 5.115 Semantic router paired-bootstrap hardening

## Purpose

5.114 established the semantic-constrained transfer router as a credible candidate ICASSP claim, with no direct collision found under alternative terminology.

This note hardens the empirical evidence by turning the negative-control "collapse" into a paired bootstrap comparison over matched target resamples.

## Protocol

Inputs:

- semantic rule run: `runs/semantic_constrained_transfer_router_threshold1_1000/`
- inverted control: `runs/semantic_constrained_transfer_router_inverted_age_only_1000/`
- all-slice control: `runs/semantic_constrained_transfer_router_all_target_slices_1000/`
- no-slice control: `runs/semantic_constrained_transfer_router_no_target_slices_1000/`

Each run has 1000 repeats per target and can be paired by:

- `target`
- `repeat`

Bootstrap:

- 20,000 bootstrap samples;
- resample paired differences within each target/control pair;
- report mean difference, 95% bootstrap CI, `P(mean <= 0)`, and paired win rate.

Interpretation:

- Semantic vs inverted is strongly positive on both targets.
- All-slice equals the semantic rule on COUGHVID by construction, because both allow the COUGHVID symptom slice.
- No-slice equals the semantic rule on TosCOVID by construction, because both route TosCOVID away from the age slice and into logistic stacking.
- The nonzero paired differences match the mechanism exactly:
  - COUGHVID needs the symptom slice;
  - TosCOVID should not use the age slice.
