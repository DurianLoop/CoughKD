# 5.123 Semantic-router target readiness checker

## Purpose

Continue toward the ICASSP 2027 objective by automating the third-target readiness gate.

This round adds a lightweight checker that decides whether a target has the registry, manifest, semantic slice field, prediction runs, and audio readiness needed for semantic-router auditing.

No download, training, or external evaluation was run.

## Script added

- `scripts/check_semantic_router_target_ready.py`

The checker validates:

1. target is registered in `TARGETS`;
2. manifest exists;
3. manifest has rows and subjects;
4. target has a `SLICE_CONFIG`;
5. slice column exists after manifest preparation;
6. slice column has at least two groups;
7. slice column is in the semantic-slice allowlist;
8. prediction runs exist;
9. `source_only` predictions exist;
10. minimum strategy pool exists;
11. for UKCOVID, audio readiness is `READY_FOR_EVALUATION`.

Outputs:

- JSON readiness report;
- Markdown readiness report.
