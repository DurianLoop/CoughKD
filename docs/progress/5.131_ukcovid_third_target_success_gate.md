# 5.131 UKCOVID third-target success gate

## Purpose

Continue toward the ICASSP 2027 objective by pre-registering the UKCOVID
third-target success/failure criteria before the large audio download and
evaluation are run. This prevents post-hoc threshold changes after seeing the
third-target result.

## Added

```text
scripts/audit_semantic_router_third_target_success.py
runs/semantic_router_third_target_success/SEMANTIC_ROUTER_THIRD_TARGET_SUCCESS.md
runs/semantic_router_third_target_success/semantic_router_third_target_success.json
```

## Pre-registered criteria

The gate targets `UKCOVID` and expects these run directories:

```text
runs/semantic_constrained_transfer_router_with_ukcovid_1000
runs/semantic_router_ukcovid_inverted_demographic_1000
runs/semantic_router_ukcovid_all_slice_1000
runs/semantic_router_ukcovid_no_slice_1000
```

Success requires:

1. Main semantic UKCOVID run has at least `1000` repeats.
2. Main mean AUROC delta versus source-only is at least `+1.00pt`.
3. Split-tail risk fields are reported.
4. Bootstrap mean confidence interval excludes zero, using `20000` samples and
   seed `20270609`.
5. Demographic-only and no-slice controls are each at least `+0.50pt` below the
   main semantic rule.

The current verdict is:

```text
NOT_READY_MISSING_ARTIFACTS
```

This is expected because UKCOVID audio and prediction runs are still missing.

## Driver integration

Updated:

```text
scripts/run_ukcovid_semantic_router_after_audio_windows.cmd
```

The post-download driver now has 16 steps. After running the main UKCOVID audit
and negative controls, it:

1. runs `scripts/audit_semantic_router_third_target_success.py`;
2. requires verdict `THIRD_TARGET_SUPPORTS_CLAIM`;
3. refreshes semantic-router submission readiness;
4. rebuilds the claim dossier;
5. refreshes submission readiness again.

If the success gate does not support the claim, the driver exits through
`third_target_not_support` and tells the user not to upgrade the ICASSP claim.
