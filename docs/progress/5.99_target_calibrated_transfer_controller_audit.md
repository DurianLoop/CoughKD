# 5.99 Target-calibrated transfer controller audit

## Purpose

5.98 showed a split pattern:

- COUGHVID benefits from a coarse symptom-slice gate, not global stacking.
- TosCOVID benefits from global target-calibrated stacking, not the symptom gate.

This note tests whether a unified target-calibrated controller can select the right strategy from calibration data alone, without looking at held-out target labels.

## New artifact

- Script: `scripts/audit_target_calibrated_transfer_controller.py`
- Main report: `runs/target_calibrated_transfer_controller/TARGET_CALIBRATED_TRANSFER_CONTROLLER.md`
- Conservative reports:
  - `runs/target_calibrated_transfer_controller_margin0p01/`
  - `runs/target_calibrated_transfer_controller_margin0p02/`

## Protocol

For each target and repeat:

1. Split target data into outer calibration and outer held-out evaluation.
2. Split outer calibration again into inner train and inner validation.
3. Use inner validation to select among:
   - source-only;
   - calibration-best single method;
   - logistic stacking;
   - target metadata slice gate, if available.
4. Refit the selected strategy on the full outer calibration split.
5. Evaluate only on the outer held-out split.

Targets:

- COUGHVID
- TosCOVID

Settings:

- repeats: 80
- outer train fraction: 0.5
- inner train fraction: 0.7
- stacking C: 1.0
- COUGHVID slice gate: `symptom_resp`, margin 0.02
- TosCOVID slice gate: `age`, margin 0.02

Three selection margins were tested:

- no explicit margin;
- require inner delta >= 0.01 before switching away from source-only;
- require inner delta >= 0.02 before switching away from source-only.

## Interpretation

This is a near miss, not a pass.

The controller often selects the intuitively correct family:

- COUGHVID mostly selects `slice_gate`;
- TosCOVID mostly selects `logistic_stacking`.

However, nested selection noise and strategy mismatch reduce held-out gains:

- COUGHVID mean delta stays below 3 points, though median is above 3 points without an explicit margin.
- TosCOVID drops below the standalone stacking gain from 5.98.
- Conservative selection margins reduce negative risk slightly but also reduce mean gains.

Therefore, the unified controller is not yet a claimable innovation. It is a useful design hint:

> the right future mechanism may need target-calibrated strategy selection, but the selector needs stronger reliability than inner-validation AUROC alone.

## Claim status

Not claimable yet.

This result does not satisfy the required ICASSP evidence standard because:

- no setting clears 3-point mean gain on both large targets;
- confidence intervals still include negative values;
- strategy selection is not reliable enough;
- the method is still close to ordinary stacking and model selection unless a more principled criterion is added.

## Next search implication

The next non-download experiment should not add more strategies. It should test a more principled selector signal, for example:

- calibration-set uncertainty of strategy gains;
- lower-confidence-bound selection instead of mean inner AUROC;
- conformal or bootstrap guarded strategy selection;
- or abandon controller selection and move to a training-time mechanism.

If none of these works, the practical path remains second-target acquisition: Cambridge or UKCOVID.
