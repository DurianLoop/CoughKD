# 5.36 查新后的 claim 收缩与下一轮实验路线

## 本轮结论

上一轮实验已经证明：当前方法候选不能 claim 成一个显著提升性能的 KD 方法。因此本轮先做查新，再决定是否还能保留“方法创新”。

查新后的判断是：

> **不能把“KD under distribution shift / target-unlabeled selection / respiratory audio KD”说成没人做过。**

但仍然存在一个更窄、更稳的 ICASSP 方向：

> **CoughKD-FailBench / CoughKD Failure Cartography：面向端侧咳嗽音频蒸馏的失败模式审计与部署评估协议。**

也就是不再声称“我们提出的方法显著超过 SOTA”，而是声称：

> 在咳嗽音频这种小数据、跨数据集漂移、标签噪声明显的端侧部署场景中，系统审计常见 KD 方法的外部泛化、校准、shortcut probe、slice robustness 与效率之间的错位关系，并给出可复现的评估协议和失败模式图谱。

## 相关工作边界

### 1. ShiftKD 已经覆盖通用 KD under distribution shift

`ShiftKD: Benchmarking Knowledge Distillation under Distribution Shift` 已经提出分布偏移下的 KD benchmark，覆盖 30+ 方法，并系统分析 KD 在不同 shift 条件下的局限。

因此我们不能 claim：

- first KD benchmark under distribution shift；
- first study showing KD may fail under shift；
- first analysis that vanilla KD is sometimes insufficient.

我们能保留的缝隙是：

- 不是通用视觉 benchmark，而是 **respiratory/cough audio**；
- 不是大模型分类精度 benchmark，而是 **ultra-light student deployment**；
- 不是只看 accuracy，而是同时看 **external AUROC、calibration、domain/task probe、slice-level negative transfer、latency、model size**；
- 特别强调 COVID/cough audio 的临床 claim 风险，不把咳嗽诊断有效性作为主战场。

来源：

- https://www.sciencedirect.com/science/article/pii/S089360802500718X

### 2. 2025 respiratory sound KD 已经存在

`Improving Respiratory Sound Classification with Architecture-Agnostic Knowledge Distillation from Ensembles` 已经在 respiratory sound classification 中做了 ensemble teacher -> student 的 soft-label KD，并在 ICHBI 上报告 SOTA。

因此我们不能 claim：

- first KD for respiratory sound classification；
- first architecture-agnostic respiratory KD；
- first soft-label distillation for respiratory audio.

我们能保留的缝隙是：

- 它主要证明 KD 能提升 respiratory sound classification；
- 我们研究的是 **当训练集和目标集发生 cough dataset shift 时，KD 为什么弱、为什么不稳定、哪些可靠性信号会误导**；
- 我们的任务不是 ICHBI 呼吸音分类，而是 Coswara -> COUGHVID 咳嗽音频端侧 student。

来源：

- https://arxiv.org/abs/2505.22027
- https://www.isca-archive.org/interspeech_2025/toikkanen25_interspeech.pdf

### 3. Coughprint 已经做了 cough representation distillation

`Coughprint: Distilled Cough Representations from Speech Foundation Model Embeddings` 已经把 speech foundation model embeddings 蒸馏为 cough representation，并强调 edge-compute deployment。

因此我们不能 claim：

- first cough representation distillation；
- first edge-focused cough student；
- first foundation model -> cough student distillation.

我们能保留的缝隙是：

- Coughprint 强调 universal cough representations 和多个 cough measurement tasks；
- 我们强调 **疾病筛查式任务中跨数据集迁移失败、校准与泛化错位、KD 负迁移审计**；
- 我们不试图超过 Coughprint 的 representation claim，而是把它作为“这个领域已经进入端侧蒸馏阶段”的强相关工作。

来源：

- https://colab.ws/articles/10.1109%2Ftim.2025.3568985
- https://ieeexplore.ieee.org/document/11024165/

### 4. Cough audio 系统综述仍强调 external validation 缺口

2025 年 wet/dry cough systematic review 指出，已有 cough type classification 研究很少，且没有进行 external validation。虽然任务不是 COVID，但这个结论支持我们把 external validation 和跨数据集审计作为核心。

来源：

- https://www.sciencedirect.com/science/article/pii/S1386505625001297

### 5. OPERA 已经覆盖 respiratory foundation model benchmark

OPERA 构建了大规模 respiratory acoustic foundation model pretraining/benchmark system，包含多源呼吸音频和多个 downstream health tasks。

因此我们不能 claim：

- first respiratory acoustic foundation benchmark；
- first foundation-model respiratory evaluation。

我们能保留的缝隙是：

- OPERA 关注 foundation model pretraining and benchmarking；
- 我们关注的是 **foundation/large teacher 能否可靠蒸馏到极小 student，并在跨 cough dataset shift 下保持部署可靠性**。

来源：

- https://opera-benchmark.github.io/

## 当前最稳 claim

更稳的论文标题：

> **CoughKD-FailBench: When Does Knowledge Distillation Help or Fail for Ultra-Light Cough Audio Models under Dataset Shift?**

核心贡献不写成“提出一个新 SOTA 方法”，而写成：

1. **Deployment-oriented KD failure benchmark**  
   构建 Coswara -> COUGHVID 的 ultra-light cough student 蒸馏评估协议，覆盖 CE、vanilla KD、target-consistency、shortcut-suppressed、disagreement-gated、probe-adversarial 等方法。

2. **Multi-evidence failure cartography**  
   同时报告 external AUROC/AUPRC、ECE、Brier、NLL、COVID sensitivity at 95% specificity、domain probe、task probe、slice-level negative transfer、params、checkpoint size、latency，展示这些指标之间并不一致。

3. **Target-slice stress test**  
   在 COUGHVID 上构造 cough quality、sex、age、respiratory-condition 等 metadata-defined target slices，证明 KD 的收益非常 slice-dependent，且 post-hoc best method 与 label-free guard selection 存在明显差距。

4. **Negative result with actionable guidance**  
   证明在当前 setting 下，简单 response KD 和若干 shortcut-aware variants 没有足够稳定的外部收益；降低 ECE 或 domain readability 不等于提高 external AUROC。这是端侧咳嗽筛查模型部署前必须审计的风险。

## 为什么这仍可能适合 ICASSP

ICASSP 接收的不一定都是“显著提升 SOTA 的模型”。如果我们把论文定位成 **audio ML deployment reliability / respiratory audio KD evaluation**，并把实验做扎实，它可以有价值：

- 任务属于 audio/speech health application；
- 主题涉及 model compression / KD / deployment；
- 结果有明确 negative finding，而不是调参失败；
- 如果再补第二个独立外部数据集，结论会更强。

3. **构造 CoughKD-FailBench summary table**  
   输出一个主表，行是方法，列是 external macro、COVID AUROC、ECE、Brier、domain probe、task probe、params、latency、positive seeds。

4. **拿第二外部数据集**  
   没有第二目标数据集前，不建议继续做新 KD 方法。

## 当前路线判断

暂时停止“提出新 KD 方法”的尝试。

继续推进：

> **CoughKD-FailBench / failure cartography / deployment reliability analysis**

达成 ICASSP claim 的最低条件：

- 至少两个外部目标或一个外部目标 + 强 slice/metadata/bootstrapped stress test；
- 明确对比 ShiftKD、Coughprint、respiratory ensemble KD；
- 不声称医学诊断有效；
- 主张是 deployment reliability protocol 和 negative-transfer evidence，而不是 SOTA classifier。
