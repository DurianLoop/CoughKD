# 5.83 Unlabeled Prediction-Geometry Selector

## Purpose

Test another no-download candidate method:

> Can target-label-free prediction geometry select a better source/CE/KD/candidate model for each external target?

The selector uses only unlabeled target posterior distributions:

- normalized entropy,
- mean confidence,
- predicted class-prior collapse,
- distance from the source-domain label prior.

Target labels are used only after selection to audit whether the rule worked.

## Literature Boundary

This space is crowded. Entropy/confidence-driven target selection and test-time/source-free adaptation have established precedents:

- Tent adapts at test time by entropy minimization: `https://arxiv.org/abs/2006.10726`
- Confidence scoring for source-free unsupervised domain adaptation: `https://proceedings.mlr.press/v162/lee22c.html`
- Recent TTA work continues to question/extend entropy proxies, e.g. `https://arxiv.org/abs/2505.20704`

Therefore, simple entropy/confidence selection is not novel enough unless it produces a strong cough-specific result.

## Per-Target Pattern

Best-looking selector family (`max_confidence` / `min_entropy` / `min_source_prior_l2`) chose:

| Target | Chosen method | Delta vs source-only | Oracle method | Oracle gap |
|---|---|---:|---|---:|
| COUGHVID | Candidate C | `+0.001808` | Candidate F | `+0.008701` |
| TosCOVID | Candidate C | `-0.018534` | CE | `+0.025836` |
| Virufy | Candidate C | `+0.039683` | CE | `+0.150794` |
| Virufyseg | Candidate C | `+0.080765` | KD | `+0.018836` |

The rule finds small-target gains but fails on TosCOVID, where confidence/entropy favors a bad negative-transfer model.

## Decision

Do not promote unlabeled prediction geometry selection to a main ICASSP 2027 method.

Reasons:

- It does not clear a 3-point gain on either large/medium target.
- It can actively hurt TosCOVID by selecting Candidate C.
- Conservative stable-only variants avoid harm but also add no gain.
- The method idea collides with existing entropy/confidence TTA and SFUDA literature.

This route can be reused only as a diagnostic feature inside a stronger guarded-transfer method, not as a standalone claim.
