## How the Gate Will Run After Approval

First, the user must accept the Hugging Face terms for `google/hear-pytorch`.

Then download:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download_hear_pytorch_windows.ps1
```

Then run the gate:

```cmd
D:\conda\envs\CoughKD\python.exe -B scripts\audit_hear_pytorch_embedding_upper_bound.py ^
  --out runs\hear_pytorch_embedding_upper_bound_seed7 ^
  --device auto ^
  --batch-size 8
```

The gate reuses the same Tos env split as previous audits:

- source artifact features: `runs/artifact_environment_audit_seed7/source_artifact_features.csv`
- Tos artifact features: `runs/artifact_environment_audit_seed7/tos_artifact_features.csv`

Hard threshold:

- Tos env-1 oracle AUROC must be at least `0.60`.
- All-Tos oracle AUROC must exceed `0.564254`.

## Decision

If HeAR clears:

- design a guarded health-foundation KD candidate,
- compare against source-only, Candidate F, and existing KD/CE baselines,
- require COUGHVID and Tos improvements before any paper claim.

If HeAR fails:

- do not continue HeAR-based KD,
- either try OPERA if approved or pivot toward guarded-transfer/failure-slice auditing.
