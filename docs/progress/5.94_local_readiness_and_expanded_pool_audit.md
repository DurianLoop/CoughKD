# 5.94 Local readiness and expanded candidate-pool audit

## Purpose

This note updates the innovation search after the UKCOVID metadata audit. The goal is to find a defensible path beyond the current COUGHVID-only margin-regularized symptom-slice transfer gate without spending large compute or downloading large datasets.

## Literature boundary update

Recent and known symptom-aware COVID cough/audio work makes a plain "use symptoms with cough audio" claim unsafe:

- SympCoughNet uses symptom information with cough analysis, so symptom-aware cough modeling is not novel by itself.
- Current web search also surfaced CoughSense, a 2026 preprint describing symptom-aware COVID-19 detection from cough sounds with foundation-model style components.
- The Nature Machine Intelligence vocal-audio reliability study remains a core risk anchor: metadata/symptoms-only comparisons and confounder control are mandatory.
- The UKCOVID Scientific Data release is still the strongest external validation target, but the local audio archive is not present.

Therefore, the current claim boundary should stay:

> target-calibrated negative-transfer gating across clinically meaningful metadata slices, with explicit metadata-only, random-slice, and symptom-stratified controls.

It should not be framed as generic symptom fusion, symptom-conditioned acoustic modeling, or cough-only COVID diagnosis.

## Current status

Not claimable yet.

The current best evidence remains COUGHVID-only:

- fixed margin 0.02, 70% calibration: mean about +4.5 points over source-only;
- random matched slice controls are near zero;
- symptom-only baseline does not explain the whole gate improvement;
- expanded candidate pool does not materially alter the policy.

The missing piece is still a second convincing external validation target. The next low-cost direction is to search for a metadata-rich public cough/audio dataset with either already available audio in the workspace or obtainable small embeddings. If that fails, the user should decide whether to authorize the large UKCOVID audio acquisition path.
