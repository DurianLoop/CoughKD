# 5.179 Metadata field risk profile

This note records a no-inference mechanism-hardening step for the ICASSP 2027
semantic-router claim.

## Purpose

The current claim says target metadata fields are not interchangeable transfer
variables. A possible reviewer objection is that any metadata field with signal
could be used as a slice gate. This audit separates:

- metadata signal;
- metadata field safety;
- deployable transfer routing.

- `scripts/summarize_metadata_field_risk_profile.py`

This strengthens the mechanism boundary. It is not a new main effect and does
not prove clinical utility.
