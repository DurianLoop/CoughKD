# 5.147 Semantic-Router Claim-Upgrade Decision Gate

Date: 2026-06-09

## Purpose

The UKCOVID third-target success gate already decides whether the pre-registered
UKCOVID experiment supports the semantic-router claim. I added one layer above
it: a claim-upgrade decision gate that states what the paper is allowed to claim
after the third-target gate succeeds, fails, or remains missing.

This prevents post-hoc claim drift after UKCOVID results arrive.

## New script

- `scripts/summarize_semantic_router_claim_upgrade_decision.py`

Outputs:

- `runs/semantic_router_claim_upgrade_decision/semantic_router_claim_upgrade_decision.json`
- `runs/semantic_router_claim_upgrade_decision/SEMANTIC_ROUTER_CLAIM_UPGRADE_DECISION.md`

Current decision:

```text
NO_UPGRADE_YET
```

Current claim level:

```text
credible two-target candidate, not final-ready
```

## Decision rules

- If the third-target success gate reports `THIRD_TARGET_SUPPORTS_CLAIM`, the
  decision is `UPGRADE_ALLOWED_AFTER_INTEGRATION`.
- If the third-target success gate reports `THIRD_TARGET_DOES_NOT_SUPPORT_CLAIM`,
  the decision is `DO_NOT_UPGRADE_PIVOT_OR_DOWNGRADE`.
- Otherwise, the decision is `NO_UPGRADE_YET`.

## Integration

- `scripts/audit_semantic_router_submission_readiness.py` now checks the
  claim-upgrade decision artifact.
- `scripts/build_semantic_router_claim_dossier.py` now includes the
  claim-upgrade decision in the third-target execution-plan requirement.
