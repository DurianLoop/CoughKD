## Diagnosis

The blocker is not the active-cough weights or training loop:

- Compact-teacher smoke completed successfully.
- `kd_weight` flowed into batches with nontrivial values.
- Checkpoint saving worked.

The blocker is PANNs / torchlibrosa initialization in the current environment:

- CPU-only `_build_teacher('panns_cnn14_16k', ...)` also stalled after `start`.
- Direct `Spectrogram(...)` construction from `torchlibrosa.stft` stalled after import.
- Pure NumPy DFT matrix construction is fast:
  - `outer 0.0`
  - `exp 0.006`
  - shape `(512, 512)`

A local fast-DFT monkey patch was added in `src/coughkd/torch_models.py`, but direct `Spectrogram` construction still stalled, so the current slow path is likely inside torchlibrosa STFT Conv1d initialization / tensor assignment / library interaction rather than the DFT math alone.
