# 2026-05-21 近期论文扫描、创新风险审查与可投稿方案

## 0. 当前判断

你的担心是成立的。下面这些单独拿出来都不能算实质创新：

- 单 teacher 到多 teacher；
- 固定 teacher 权重到 confidence / entropy / calibration weighting；
- response KD 到 feature / embedding / relation / calibration KD；
- 单 Coswara 到跨 Coswara / COUGHVID / DiCOVA；
- 只看 AUROC 到同时看 Params / FLOPs / latency / calibration。

这些都是已有文献中已经反复出现的组件。它们可以作为实验规范、baseline 或 evaluation protocol，但不能直接写成 AAAI 级别的方法贡献。

更稳的思路应该是：找到咳嗽音频场景里一个足够具体、足够难、已有方法没有直接解决的问题，然后设计一个能被实验证明有效的机制。

我建议把问题收紧为：

> 在咳嗽音频小数据、标签噪声、跨数据集漂移和 teacher 本身不可靠的条件下，如何判断哪些 teacher 知识值得蒸馏、哪些 teacher 知识会造成负迁移，并把这种判断显式用于极小 student 的训练。

这比“我用了多教师、多层 KD、跨域验证”更像一个方法问题。

## 3. 已有想法为什么还不够

### 3.1 多教师不是创新

已有：

- CA-MKD 做 confidence-aware multi-teacher；
- DE-MKD 做 entropy-based teacher weighting；
- 2025 Multi-Distillation 做 speech/music 多领域 teacher；
- 2025 respiratory ensemble KD 已经把 ensemble soft labels 用在 respiratory sound classification。

所以我们不能写：

> We propose multi-teacher distillation.

只能写：

> We investigate when teacher knowledge should not be trusted in noisy, shifted cough audio distillation.

### 3.2 可靠性权重也不是创新

已有 teacher confidence、entropy、calibration、agreement weighting。我们的机会不是“再加一个权重”，而是把权重从静态 teacher quality 改成 **sample-level distillability**：

> 不是 teacher A 比 teacher B 更可靠，而是对于样本 x、数据域 d、频段 f、扰动集合 A，teacher 的哪些知识可蒸馏，哪些知识应被拒绝。

这才是可以被审稿人认真讨论的点。

### 3.3 多层 KD 不是创新

Response / feature / embedding / relation / contrastive KD 都有成熟前作。我们的机会是提出：

> 不同层级的 teacher knowledge 在跨域咳嗽音频里具有不同风险，应被不同的 distillability gate 控制。

例如：

- response KD 容易复制 teacher 的 label shortcut；
- embedding KD 容易复制 domain/device shortcut；
- relation KD 可能更稳定，但也可能保留 dataset-specific clusters；
- calibration KD 只有在 teacher 自身校准后才有价值。

所以我们需要证明：

> 盲目加多层 KD 可能更差；我们的方法能识别并抑制有害蒸馏。

## 4. 我建议的 3 个可投稿创新方案

## 方案 A：Distillability-Guided CoughKD

### 核心问题

不是所有 teacher 输出都值得学。尤其在 cough COVID 这种小数据、弱标签、跨数据集漂移任务里，teacher 可能学到的是：

- 数据集来源；
- 录音设备；
- 背景噪声；
- 症状严重程度；
- 音频质量；
- 类别先验；
- 训练集 shortcut。

因此，核心创新可以定义为：

> 对每个样本估计 teacher knowledge 的 distillability，只在 teacher 知识稳定、跨扰动一致、跨 teacher 一致、跨域不过分偏移时蒸馏；否则降低 KD 权重，回退到 CE / consistency / supervised contrastive learning。

### 方法设计

给每个样本 x 和 teacher t 定义 distillability score：

```text
D_t(x) = S_aug(t, x)
       * S_cal(t, x)
       * S_agree(t, x)
       * S_domain(t, x)
       * S_quality(x)
```

其中：

- `S_aug`：teacher 在弱增强/强增强/噪声/重采样/增益变化下的预测和 embedding 是否稳定；
- `S_cal`：teacher 在 validation calibration bins 上的局部校准可信度；
- `S_agree`：多个 teacher 在 logits 或 embedding relation 上是否一致；
- `S_domain`：样本 embedding 是否接近训练域原型，是否像 OOD；
- `S_quality`：音频质量，包含时长、能量、SNR、静音比例、clipping、metadata quality。

训练 loss：

```text
L = L_CE
  + lambda_r * D_t(x) * L_responseKD
  + lambda_e * D_t(x) * L_embeddingKD
  + lambda_rel * D_batch * L_relationKD
  + lambda_cons * L_student_consistency
```

关键点：`D_t(x)` 不是简单 confidence weighting，而是 **distillability gating**。它的目标不是找最自信 teacher，而是判断 teacher 知识是否适合被 student 学。

### 和已有工作的区别

| 已有工作 | 已有内容 | 我们的差异 |
|---|---|---|
| CA-MKD | teacher confidence weighting | 没有针对 cough/audio domain shift 的 distillability |
| DE-MKD | entropy-based multi-teacher weighting | 主要从输出分布看 teacher，不看增强稳定性、域偏移、音频质量 |
| Teacher calibration KD | 校准 teacher 改善 KD | 没有处理跨数据集咳嗽音频负迁移 |
| Respiratory ensemble KD 2025 | ensemble soft label 提升 ICBHI | 不是 cough COVID，不处理 teacher 是否有害 |
| SCKD 2026 | selective cross-domain AST adapter KD | 面向 AST adapter 多域融合，不是极小 cough student，也不是 health acoustic confounding |

### 实验设计

主实验：

- 数据：Coswara train/val/test；
- external：COUGHVID、DiCOVA；
- teacher：PANNs、HeAR、OPERA、BEATs；
- student：DepthwiseStudent、MobileNetV3-small、BC-ResNet；
- baseline：
  - CE-only；
  - vanilla KD；
  - confidence KD；
  - entropy KD；
  - calibration KD；
  - feature / relation KD；
  - respiratory ensemble KD 风格 soft labels；
  - ours。

核心表：

| Method | In-domain AUROC | External AUROC | External drop | ECE | Params | FLOPs | CPU ms |
|---|---:|---:|---:|---:|---:|---:|---:|

关键 ablation：

| Variant | Aug stability | Calibration | Agreement | Domain typicality | Quality | External AUROC | ECE |
|---|---|---|---|---|---|---:|---:|

失败判据：

- 如果 ours 只提升 in-domain，不提升 external，则不能投 AAAI，只能写成工程报告；
- 如果 ours 和 confidence/entropy KD 差不多，则 distillability 定义不够新；
- 如果只在一个 teacher 有效，则 claim 要收缩到 teacher-specific。

### 工作量

中等偏高，但可控。

- 1 周：实现 teacher prediction/embedding cache；
- 1 周：实现增强稳定性和 quality score；
- 1 周：实现 distillability-gated KD；
- 1 周：跑 Coswara 单 seed；
- 2 周：3 seeds + ablation；
- 2 周：external validation；
- 1 周：效率/校准/图表。

总计约 8 周可以形成可投稿实验骨架。

### 投稿定位

- AAAI 2027：如果 external validation 和 ablation 很强；
- ICASSP 2027：如果方法贡献一般但音频实验完整；
- Interspeech 2027：如果强调 respiratory/audio representation；
- BHI / JBHI：如果后续补临床严谨性和 metadata/subgroup 分析。

## 方案 B：Shortcut-Resistant Distillation for Cough Audio

### 核心问题

Nature Machine Intelligence 2024 的核心质疑是：COVID cough 模型可能学到症状、招募渠道和混杂因素，而不是疾病声学信号。

我们可以不声称解决临床因果，但可以提出一个更窄的 ML 问题：

> 在蒸馏过程中显式抑制 teacher/student 表征中的 dataset、device、quality、symptom shortcut，使 student 学到更稳定的 cough representation。

### 方法设计

定义三类 nuisance variables：

- domain：Coswara / COUGHVID / DiCOVA；
- quality/device proxy：SNR、clipping、duration、energy、sampling artifacts；
- metadata proxy：age、gender、symptom presence，如果数据集可用。

Student embedding 同时接三个头：

1. label classifier；
2. domain/device/quality adversarial head；
3. teacher distillation head。

训练目标：

```text
L = L_CE
  + L_KD
  - lambda_adv * L_domain_predict
  + lambda_inv * L_aug_invariance
  + lambda_rel * L_cross_domain_relation
```

其中 `-L_domain_predict` 通过 gradient reversal 实现，让 student embedding 不容易预测数据集来源或设备质量。

更关键的一步：

> teacher embedding 也先做 shortcut audit。如果 teacher embedding 可以很容易预测 domain/device/quality，则这些 teacher 层不用于 embedding KD，只保留 response 或 relation。

这叫 **teacher shortcut audit before distillation**。

### 和已有工作的区别

已有 domain adversarial training 很多；已有 KD 也很多。差异要落在：

> 不是泛泛做 domain adaptation，而是在 KD 前审计 teacher 表征里的 shortcut，并根据审计结果选择蒸馏哪些层、哪些 teacher、哪些样本。

### 实验设计

必要实验：

1. Teacher shortcut audit：
   - 用 frozen teacher embedding 训练 domain classifier；
   - 如果 domain AUC 很高，说明 teacher embedding 含强 domain shortcut。

2. Student shortcut audit：
   - CE-only；
   - vanilla KD；
   - ours；
   - 比较 student embedding 的 domain predictability。

3. External validation：
   - Coswara -> COUGHVID；
   - Coswara -> DiCOVA；
   - leave-one-dataset-out。

4. 性能与 shortcut trade-off：
   - label AUROC；
   - domain classifier AUROC，越低越好；
   - ECE；
   - external drop。

核心图：

```text
x-axis: domain predictability of student embedding
y-axis: external AUROC
```

理想结果：ours 在更低 domain predictability 下有更高 external AUROC。

### 工作量

中等。

- 需要 external datasets；
- 需要实现 domain adversarial head；
- 需要 teacher embedding cache；
- 不需要复杂新模型。

大约 6-8 周能做出主结果。

### 风险

- 如果 external datasets label 不兼容，实验会很乱；
- 如果去 domain 后 in-domain 性能显著下降，需要把 claim 改成 robustness trade-off；
- 如果缺少 device/metadata，只能用 domain 和 signal quality proxy。

### 投稿定位

- AAAI 2027：如果 shortcut audit + distillation selection 做得清楚；
- ICASSP 2027：如果主打 cross-domain cough audio robustness；
- Interspeech 2027：如果补足 respiratory audio analysis。

## 方案 C：Budget-Aware Retention Distillation

### 核心问题

我们不是为了追最高 AUROC，而是为了端侧部署。那就不应该只优化性能，而要优化：

> 在给定参数量、FLOPs、latency 和 calibration 约束下，student 能保留多少 teacher 的有效能力。

这和普通 KD 不同：普通 KD 的目标是 student accuracy；我们的目标是 deployment-constrained teacher retention。

### 方法设计

定义多目标指标：

```text
Retention = Student_AUROC / Teacher_AUROC

RobustRetention = External_Student_AUROC / InDomain_Teacher_AUROC

CalibratedRetention = Retention * (1 - ECE_student)

EfficiencyScore = CalibratedRetention / log(Params or FLOPs)
```

训练时不一定直接反传这些指标，而是在模型选择和 KD 权重搜索时使用：

- 小 student 用更强 relation/embedding KD；
- 中等 student 用 response + calibration KD；
- 大 student 用 CE + weak KD，防止过拟合 teacher；
- 根据 validation 上的 retention/latency 自动选择 KD 配方。

可以做一个轻量策略：

```text
for each student budget:
    estimate capacity gap to teacher
    choose KD loss weights by validation retention and calibration
```

这个方案的方法创新较弱，但非常适合 ICASSP/部署型 paper。

### 实验设计

必须有 Pareto 图：

- x-axis：Params / FLOPs / CPU latency；
- y-axis：AUROC / external AUROC / calibrated retention；
- 点：CE-only、vanilla KD、ours。

## 6. 具体方法草案

### 6.1 Teacher consistency under cough-preserving perturbations

对同一条咳嗽音频生成多个增强版本：

- gain perturbation；
- background noise；
- time shift；
- SpecAugment；
- resampling / codec perturbation；
- cough segment crop。

如果 teacher 对这些版本的 logits 和 embedding 都稳定，则说明 teacher knowledge 对该样本更可蒸馏。

指标：

```text
S_aug = exp(- JS(p_t(x), p_t(aug(x))))
      * exp(- cosine_distance(z_t(x), z_t(aug(x))))
```

### 6.2 Teacher calibration locality

不是只看 teacher 总体 ECE，而是按 validation confidence bin 估计局部可靠性。

如果某样本落在 teacher 过度自信但错误率高的 bin，则降低 KD 权重。

```text
S_cal = 1 - local_ECE_bin
```

### 6.3 Cross-teacher agreement without requiring all teachers

第一阶段只用 PANNs teacher 时，`S_agree` 可以关闭。

第二阶段加入 HeAR / OPERA / BEATs 后：

```text
S_agree = mean pairwise agreement among teacher logits / embeddings
```

关键是：多 teacher 不是创新，**用 teacher agreement 估计 distillability** 才是方法的一部分。

### 6.4 Domain typicality

用 teacher/student embedding 计算每个数据集的 prototype。

如果一个样本距离所有训练域 prototype 都远，说明可能是 OOD 或低质量样本，不适合强蒸馏。

```text
S_domain = exp(- min_d distance(z_t(x), prototype_d))
```

### 6.5 Audio quality gate

根据音频本身估计质量：

- duration；
- RMS energy；
- silence ratio；
- clipping ratio；
- spectral flatness；
- SNR proxy。

低质量样本减少 KD，避免 teacher 在噪声样本上的错误软标签污染 student。

### 6.6 Final loss

```text
L = L_CE
  + lambda_r * D(x) * KL(p_s, p_t)
  + lambda_e * D(x) * MSE(g(z_s), z_t)
  + lambda_rel * D_batch * ||R_s - R_t||_2
  + lambda_cons * ||p_s(x) - p_s(aug(x))||_2
```

其中：

```text
D(x) = normalize(S_aug * S_cal * S_agree * S_domain * S_quality)
```

注意：低 `D(x)` 时不是丢弃样本，而是从 teacher-supervised training 切换到 label-supervised / consistency training。

## 7. 实验路线

### Stage 0：复现旧 baseline

当前正在跑：

- PANNs CNN14 16 kHz teacher；
- DepthwiseStudent；
- response KD；
- Coswara cough split。

目标：确认旧同学结果是否可复现。

旧记录：

| Model | Macro OVR AUROC |
|---|---:|
| PANNs teacher | 0.6134 |
| CE-only student | 0.5639 |
| KD student | 0.5664 |

这个结果将作为 vanilla KD baseline。

### Stage 1：单 teacher distillability

只用 PANNs，先不引入多 teacher。

实验：

| Method | 目的 |
|---|---|
| CE-only | student 下限 |
| vanilla response KD | 旧 baseline |
| + augmentation consistency score | 验证 S_aug |
| + calibration gate | 验证 S_cal |
| + quality gate | 验证 S_quality |
| full single-teacher D-KD | 验证 distillability |

如果单 teacher 阶段就能超过 vanilla KD，说明方法有基本价值。

### Stage 2：多 teacher 但不堆组合

只选 3 个 teacher：

- PANNs CNN14；
- HeAR；
- OPERA 或 BEATs。

实验不是穷举 teacher × student × KD，而是：

| Method | Teacher use |
|---|---|
| best single teacher KD | 单 teacher 上限 |
| naive average teacher KD | 多 teacher 简单平均 |
| confidence-weighted KD | 已有 baseline |
| entropy-weighted KD | 已有 baseline |
| distillability-guided KD | ours |

### Stage 3：external validation

至少做：

- Coswara -> COUGHVID；
- Coswara -> DiCOVA；
- 如果时间够，COUGHVID + Coswara -> DiCOVA。

核心指标：

- in-domain AUROC；
- external AUROC；
- external drop；
- AUPRC；
- macro-F1；
- sensitivity at 95% specificity；
- ECE；
- Brier；
- Params；
- FLOPs；
- CPU latency。

### Stage 4：效率与部署

Student 只选 3 个：

- DepthwiseStudent：极小，当前已有；
- MobileNetV3-small：成熟端侧 baseline；
- BC-ResNet：音频轻量 CNN baseline。

不要一开始跑 EfficientNet-B0、YAMNet 等太多模型，容易失焦。

## 8. 预期贡献写法

不要写：

> We propose multi-teacher multi-level KD for COVID cough diagnosis.

建议写：

> We study harmful teacher transfer in ultra-light cough audio distillation under dataset shift, and propose a distillability-guided training framework that selectively transfers teacher knowledge only when it is stable under perturbation, locally calibrated, domain-typical, and audio-quality reliable.

中文：

> 我们研究跨数据集咳嗽音频轻量化蒸馏中的有害 teacher transfer 问题，并提出可蒸馏性感知训练框架，只在 teacher 知识满足扰动稳定、局部校准、域内典型和音频质量可靠时进行蒸馏。

贡献可以写成：

1. 提出 cough audio distillability 的问题定义，用于刻画 teacher knowledge 是否适合迁移到极小 student；
2. 设计 distillability-guided KD，将增强稳定性、局部校准、域典型性和音频质量纳入 sample-level KD gating；
3. 系统证明 vanilla KD、confidence KD、entropy KD 在咳嗽音频跨域场景下可能产生负迁移，而我们的 gating 能降低 external drop；
4. 在 Coswara、COUGHVID、DiCOVA 上报告性能、校准和部署效率，避免单数据集 COVID 诊断 claim。

这更像 ICASSP / Interspeech paper，不一定 AAAI，但科学上更诚实。

这时我们主打 OPERA/HeAR 到 tiny student 的压缩和 external retention。
