## Rule

Fit the same source artifact KMeans (`k=2`) used by Candidate F.

Let `source_minority_prop` be the proportion of source clips assigned to the source-minority artifact env.

For each target:

- compute the target proportion assigned to the same source-minority env,
- reject Candidate F if `target_minority_prop - source_minority_prop > 0.10`,
- otherwise allow Candidate F.

This is no-label at target time because it only uses audio-derived artifact features and source-fitted clusters.

## Decision

Candidate H does not clear the requested 3-5 point method gate.

Positive readout:

- The no-label artifact-composition rule correctly allows Candidate F on COUGHVID.
- It correctly rejects Candidate F on Tos, where artifact-IRM hurts.
- This supports the guarded-transfer intuition.

Negative readout:

- The absolute gains are too small for a standalone method claim.
- The replay only covers two artifact-feature-cached external targets.
- It is retrospective, so it should not be presented as a validated deployment policy.

## Implication

Do not write Candidate H as the main positive ICASSP method.

It can still become a supporting analysis if the final paper pivots to guarded transfer:

- "unlabeled target artifact composition can flag one negative-transfer case,"
- but not "our method improves external COVID cough screening by 3-5 points."
