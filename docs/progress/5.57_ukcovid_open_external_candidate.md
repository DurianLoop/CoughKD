# 5.57 UK COVID-19 Vocal Audio Public External Candidate

日期：2026-06-01

## 本轮目的

继续推进 `/goal` 时，当前最大 blocker 是缺少第二个大外部目标。之前 Cambridge / ComParE CCS 是最优目标，但需要 DTA。为了避免只等待审批，本轮检索并确认了一个更可立即推进的公开候选：UK COVID-19 Vocal Audio Dataset open access。

## 新候选数据集

### UK COVID-19 Vocal Audio Dataset Open Access

链接：

- Zenodo open-access record: https://zenodo.org/records/10043978
- Scientific Data paper: https://www.nature.com/articles/s41597-024-03492-w
- Alan Turing record: https://atiro.turing.ac.uk/esploro/outputs/dataset/The-UK-COVID-19-Vocal-Audio-Dataset/9922381609548

关键信息：

- 公开 Zenodo 记录；
- 包含 cough 和 exhalation 音频，open release 不含 speech；
- 包含 `audio_metadata.csv`、`participant_metadata.csv`、`train_test_splits.csv`；
- 标签来自 PCR-referenced COVID test information；
- 音频 archive 很大，约 53GB，因此不能直接贸然全量下载；
- 从数据来源和标签质量看，它比 Virufy tiny 更适合作为第二公开外部目标，也比 DiCOVA 更独立。

## 新增脚本

1. `scripts/build_ukcovid_manifest.py`

用途：把 UK COVID-19 Vocal Audio metadata 转成 CoughKD manifest。支持：

- 自动/手动识别 participant id、label、cough audio path columns；
- 合并 participant metadata 和 train/test splits；
- `--allow-missing-audio` metadata-only 模式，用于在没有下载 53GB 音频前先审计标签和路径；
- 下载音频后去掉 `--allow-missing-audio` 生成正式 manifest。

2. `scripts/download_ukcovid_metadata_windows.cmd`

用途：只下载 Zenodo 上的小型 metadata/split/readme 文件，不下载大音频 archive。

## 当前判断

UK COVID-19 Vocal Audio 是目前最有希望打破 `CONDITIONAL_GO_AUDIT_PAPER_NEEDS_SECOND_EXTERNAL` 的公开路线。它不会替代 Cambridge 的最高价值，但可以在 DTA 等待期间直接推进 evidence package。

## 下一步

1. 用 `scripts/download_ukcovid_metadata_windows.cmd` 下载 metadata。
2. 运行 `scripts/build_ukcovid_manifest.py --allow-missing-audio`，先确认标签分布、split 和 cough path columns。
3. 如果 metadata 分布合适，再决定是否下载 53GB 音频 archive，或先抽取部分 archive 做 pilot。
4. 下载并解压音频后，去掉 `--allow-missing-audio` 生成正式 manifest。
5. 运行 `scripts/onboard_external_target.py --target-tag ukcovid_open`。
