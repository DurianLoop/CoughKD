# 5.65 Active-Cough Selective KD Gate

## Purpose

This round continues the ICASSP 2027 innovation loop, but keeps the search bounded.
The current evidence still does not support a strong method-superiority claim:

- COUGHVID best KD/TCD delta over source-only is only `+0.000701` macro AUROC.
- Tos COVID-19 2021 official test prefers CE-only post hoc; vanilla KD and guard-selected TCD are negative.
- COUGHVID slice LOSO guard selection is unstable: `7/25` negative selections and mean selected delta `-0.000201`.

Therefore, the next method candidate must first pass a hard, low-cost gate before any three-seed expansion or paper claim.

## Literature Collision Check

The candidate is constrained by nearby work:

- ShiftKD, Neural Networks 2025: KD under distribution shift is already benchmarked in general settings. We cannot claim first KD under shift.
  - https://www.sciencedirect.com/science/article/pii/S089360802500718X
- Coughprint, IEEE TIM 2025: cough representation distillation already exists. We cannot claim first cough distillation.
  - https://ieeexplore.ieee.org/document/11024165/
- DNDT/DNDF, Expert Systems with Applications 2026: cross-dataset COVID cough classification already exists. We cannot claim first cross-dataset cough-COVID evaluation.
  - https://www.sciencedirect.com/science/article/pii/S0957417426001491
- CoughSense, arXiv 2026: active-frame pooling for cough audio is a close collision risk.
  - https://arxiv.org/abs/2606.02998

The remaining plausible novelty is narrower:

> Active-cough selective distillation for ultra-light cough students under public-dataset shift: reduce teacher pressure on source recordings whose cough-active evidence is weak, rather than claiming active-frame pooling or cough representation learning itself.

This is only a candidate. It is not claimable unless external target results are clearly positive.

## Candidate D: Active-Cough Selective KD

Hypothesis:

Teacher response KD may transfer background, silence, device, or recruitment shortcuts when cough-active evidence is weak. A source-side active-cough quality signal can down-weight the KD term while leaving CE supervision intact.

Implementation strategy:

- Add `scripts/build_active_cough_kd_weights.py`.
- Use waveform frame RMS to estimate active cough coverage, energy concentration, and active/noise contrast.
- Output a CSV with `recording_id` and `kd_weight`.
- Reuse the existing `scripts/train_shortcut_suppressed_student.py` path, because that script already applies `kd_weight` only to KD.
- Do not use target labels to build weights.

This avoids modifying the model architecture and keeps the first test cheap and falsifiable.

## Hard Gate

Reference values:

- COUGHVID source-only macro AUROC: `0.5146`
- COUGHVID best existing KD/TCD macro AUROC: `0.5153`
- Tos source-only macro AUROC: `0.5013`
- Tos post-hoc CE macro AUROC: `0.5095`

Decision rule after seed 7:

- Stop candidate D if COUGHVID macro AUROC is below `0.525` or Tos macro AUROC is below `0.510`.
- Continue to seeds 11 and 23 only if candidate D clears at least one target by about `+0.01` and does not strongly regress on the other.
- Consider a method claim only if three-seed mean improvement approaches `+0.03` macro AUROC on at least one main external target and the second target is non-negative.
- If results remain at the `+0.001` level, do not tune this direction further; return to literature search for the next candidate.

## Claim Boundary

If candidate D succeeds, the possible claim is not:

- first cough KD;
- first active-frame cough model;
- first KD under shift;
- SOTA COVID cough classifier;
- clinical COVID diagnosis.

The only possible method claim would be:

> Active-cough selective teacher pressure improves ultra-light cough KD robustness under public-dataset shift, validated against source-only, CE-only, vanilla KD, and existing TCD/guard variants across independent external targets.

This claim remains unproven until the hard gate is run.
