# 5.44 Virufy Segmented Subject-Level Audit

## 为什么补这个实验

Virufy segmented manifest 有 121 个 clips，但这些 clips 只来自 16 个原始录音/subject。片段级 AUROC 不能直接当成 121 个独立样本，否则会高估外部证据强度。

因此本轮新增 subject-level 聚合评估：

```powershell
cd D:\CoughKD\AAAI
D:\conda\envs\CoughKD\python.exe scripts\aggregate_external_predictions_by_subject.py `
  --manifest manifests\virufy_segmented_external.csv `
  --target-tag virufyseg
```

聚合方式：

1. 读取每个 `runs/external_virufyseg_<method>_seed<seed>/predictions.csv`。
2. 用 `manifest` 的 `recording_id -> subject_id` 映射把片段归回原始录音。
3. 对同一 `subject_id` 的 class probabilities 取平均。
4. 在 16 个 subject 上重新计算 macro OVR AUROC、COVID AUROC 和 macro AUPRC。

新增文件：

- `scripts/aggregate_external_predictions_by_subject.py`
- `runs/subject_aggregate_virufyseg/SUBJECT_AGGREGATE_REPORT.md`
- `runs/subject_aggregate_virufyseg/method_summary.csv`
- 每个外部 run 目录下新增 `subject_predictions.csv` 与 `subject_metrics.json`

## 和片段级结果的关系

片段级 Virufy segmented：

- source-only macro AUROC: `0.5877`
- post-hoc best: vanilla KD `0.6392`
- vanilla KD delta: `+0.051465`
- guard selected: `tcd_conf035`
- guard delta: `+0.003092`

subject-level Virufy segmented：

- source-only macro AUROC: `0.764550`
- post-hoc best: `candidate_c` `0.854497`
- vanilla KD delta: `+0.047619`
- guard 方法 `tcd_conf035` 仍然只有小收益 `+0.007937`

这个结果不应该被包装成强方法 claim，因为有效独立样本数仍然只有 16。但是它对 ShiftAudit 主线有价值：

1. clip-level 和 subject-level 的最佳方法不同；
2. target-unlabeled guard 没有选到 post-hoc best；
3. vanilla KD 在这个小 stress target 上有明显正收益，但在 COUGHVID 上为负；
4. 这说明 KD 是否有效高度依赖 target composition、preprocessing granularity 和 evaluation unit。

## 当前判断

这个实验没有把项目从分析型论文扭回“新 KD 方法显著有效”的路线。相反，它加强了分析型论文的中心论点：

> Ultra-light cough KD under dataset shift is not only method-sensitive, but also evaluation-unit-sensitive. Clip-level gains, subject-level gains, calibration, and target-unlabeled selection can point to different conclusions, so deployment-oriented cough distillation needs a failure audit protocol rather than a single aggregate AUROC table.

下一步仍然是拿到更大的第二外部目标，优先级：

1. Cambridge COVID-19 Sounds / ComParE CCS；
2. DiCOVA only as Coswara-derived auxiliary protocol with overlap control；
3. CODA TB / cough-type target if we pivot to generic cough deployment reliability。
