## Added

Created:

```text
scripts/run_ukcovid_semantic_router_after_audio_windows.cmd
```

The driver is meant to be run only after the UKCOVID split audio archive has
been downloaded and extracted under:

```text
D:\CoughKD\external\ukcovid_open
```

It performs the post-download chain:

1. Check UKCOVID audio readiness.
2. Gate on `READY_FOR_EVALUATION`.
3. Rebuild `manifests/ukcovid_open_test_external.csv` with
   `--recursive-audio-search`.
4. Run Coswara-vs-UKCOVID overlap audit.
5. Onboard UKCOVID with the existing external model set.
6. Check semantic-router target readiness.
7. Gate on `READY_FOR_SEMANTIC_ROUTER_AUDIT`.
8. Run the 1000-repeat semantic-router audit on COUGHVID, TosCOVID, and
   UKCOVID.
9. Run UKCOVID demographic-only, all-slice, and no-slice negative controls.
10. Refresh the semantic-router submission-readiness gate.

The script supports a no-execution preview:

```cmd
scripts\run_ukcovid_semantic_router_after_audio_windows.cmd --dry-run
```
