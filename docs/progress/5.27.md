# 2026-05-27 Stage 2b 结果分析与下一步指示

## 1. 结论

Stage 2b 已完成。结论很明确：

> **温和版 SA-KD 仍然没有改善 COUGHVID external AUROC，也没有降低 student embedding 的 dataset-domain 可分性。**

因此，当前的 sample-level shortcut weighting 不能作为论文主方法继续推进。它可以保留为一个重要分析结果：  
**简单地根据 source/domain-typicality 压低 KD 权重，并不能减少 shortcut transfer，反而会损伤可迁移的任务表征。**

### 2.3 Domain probe

| model | dataset-domain AUC | task-label AUC |
|---|---:|---:|
| CE student | 0.7238 | 0.5836 |
| vanilla KD | 0.7145 | 0.6347 |
| SA-KD tempered full | 0.7384 | 0.5718 |
| SA-KD tempered domain | 0.7350 | 0.5563 |
| SA-KD mild full | 0.7388 | 0.5707 |

现象：

- vanilla KD 反而是 domain AUC 最低、task-label AUC 最高；
- SA-KD 没有降低 domain 可分性；
- SA-KD 损伤了 task representation。

这说明当前方法不能写成：

> Our shortcut-audited KD reduces shortcut transfer.

更准确的写法应该是：

> Naively suppressing domain-typical teacher signals is insufficient for cough-audio distillation and may remove transferable task information together with shortcut cues.

## 3. 关键判断

当前实验说明：

1. Coswara 与 COUGHVID 的 domain shift 极强，低阶声学统计即可把两个数据集区分到接近完美；
2. 但这些 domain-typical 信号不一定都是纯副作用，它们可能和 cough quality、症状分布、设备、采样协议、标签噪声纠缠在一起；
3. 因此，按样本降低 KD 权重不是一个足够细的手术刀；
4. 继续在 sample weighting 上调参，容易变成工程试错，不适合作为 AAAI 主线。

## 4. 下一步路线

### 4.1 立即停止

停止继续大规模跑：

```text
quality/domain/full sample-weighted KD
floor / power sweep
```

这些可以作为 negative analysis 保留，但不再作为主方法。

### 4.2 先做公平 baseline 稳定性

下一步先把已有 baseline 做扎实：

1. CE student；
2. vanilla KD；
3. feature KD；
4. embedding KD；
5. relation KD；
6. CE + unlabeled COUGHVID consistency；
7. KD + unlabeled COUGHVID consistency。

必须统一：

- 同一个 teacher checkpoint；
- 同一个 student；
- 同一个 split；
- 同一个 seed 列表；
- 同一个 external eval；
- 同一个 domain probe。

建议先跑 seeds：

```text
7, 11, 23
```

### 4.3 方法方向改为 target-consistency，而不是 source-sample filtering

新的更稳方向：

> **Target-Consistent Distillation for Ultra-Light Cough Audio Models**

核心思想：

- 不再判断 source 样本哪些该学、哪些不该学；
- 而是在无标签 COUGHVID-adapt 上要求 student 对扰动保持一致；
- 让 student 在目标域音频分布上适配输入扰动、录音条件和质量变化；
- 同时保留 Coswara 监督标签与 teacher KD。

训练目标：

```text
L = L_CE(source)
  + lambda_kd * L_KD(source)
  + lambda_tgt * L_consistency(target_unlabeled)
```

其中 target consistency 可以包括：

- weak/strong augmentation consistency；
- entropy minimization；
- confidence threshold pseudo-label；
- teacher-student consistency on COUGHVID-adapt。

这比 sample filtering 更符合当前证据，因为问题不是“哪些 source 样本不要学”，而是“student 没见过 target-domain 音频分布”。

### 4.4 成功标准

新方法至少要满足：

1. COUGHVID-test macro AUROC > vanilla KD `0.5142`；
2. COVID AUROC > vanilla KD `0.5179`；
3. Coswara in-domain AUROC 不显著低于 `0.5577`；
4. task probe AUC 不低于 CE student；
5. 最好 domain probe AUC 不升高。

### 4.5 如果 target-consistency 仍然失败

如果 target-consistency 也无法提升 external AUROC，那么论文方向应调整为：

> **When Does Knowledge Distillation Fail for Ultra-Light Cough Audio Models under Dataset Shift?**

这可以是一篇偏分析/benchmark 的 ICASSP 方向文章，而不是 AAAI 方法主文。

## 5. 给简历项目的定位

简历中不要写“提出了最终有效的 COVID 诊断模型”。当前最稳的包装是：

## 6. Stage 3 已实现：Target-Consistent Distillation

新增训练脚本：

```text
scripts/train_target_consistency_student.py
```

新增一键运行脚本：

```text
scripts/run_target_consistency_stage3_windows.cmd
```

### 6.1 方法

Stage 3 不再继续做 source sample filtering，而是使用 COUGHVID-adapt 的无标签目标域音频做 consistency regularization：

```text
L = L_CE(source)
  + lambda_kd * L_KD(source)
  + lambda_tgt * L_consistency(target_unlabeled)
```

其中：

- `source` = Coswara train；
- `target_unlabeled` = COUGHVID adapt；
- teacher = Stage 1 已训练好的 PANNs teacher；
- student = Stage 1 vanilla KD student 初始化；
- target consistency = weak/strong augmentation 后 student 输出分布保持一致。

### 6.2 已实现变体

一键脚本会跑三组：

| variant | target weight | confidence threshold | 说明 |
|---|---:|---:|---|
| `stage3_tcd_low_seed7` | 0.10 | 0.00 | 保守一致性 |
| `stage3_tcd_mid_seed7` | 0.30 | 0.00 | 中等一致性 |
| `stage3_tcd_conf_seed7` | 0.30 | 0.45 | 高置信目标样本一致性 |

每组都会：

1. 在 Coswara source 上继续 CE + KD；
2. 在 COUGHVID-adapt 上做 target consistency；
3. 保存 `student_best.pt`；
4. 在 COUGHVID-test 上评估；
5. 参与 Coswara/COUGHVID domain probe。
