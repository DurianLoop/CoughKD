## Interpretation

The local evidence is now clear:

- The current source-trained cough embeddings do not contain enough recoverable Tos env-1 signal for a strong positive transfer claim.
- PANNs did not clear the Tos env-1 foundation gate.
- Guarded transfer replay improves the failure mode but its mean gain is only about `+0.0056`, far below the requested 3-5 point target.
- Existing small external positive signals are too small and unstable to carry the paper.

## Recommendation

If the priority is still a positive 3-5 point ICASSP 2027 method claim, the next action should be one of:

1. **UKCOVID audio approval**: highest-value validation route because it provides a large external target.
2. **HeAR PyTorch gated-weight access**: highest-value new-method route because the environment is already ready and the asset is health-acoustic.

If neither external action is approved, the defensible direction is to pivot the paper toward a guarded-transfer / failure-slice claim rather than keep searching locally for an overstated positive gain.
