# 5.81 Prediction Ensemble Frontier and Literature Collision

## Purpose

Test one cheap remaining possibility before asking for new assets:

> Do existing prediction files already contain a no-retraining ensemble that can support a 3-5 point ICASSP-style positive claim?

This avoids another expensive training loop and directly checks whether the current model pool has usable positive signal.

## Literature Boundary

Recent nearby work already covers much of the obvious space:

- respiratory/cough knowledge distillation and foundation-model transfer,
- cough/COVID acoustic representation learning,
- source-free or test-time adaptation for audio domain shift,
- respiratory foundation embeddings such as OPERA and health-acoustic models such as HeAR.

Therefore, a simple seed ensemble, CE/KD ensemble, or generic audio adaptation cannot be claimed as novel by itself. It can only support the paper if attached to a stronger, cough-specific failure-slice or risk-control mechanism.

## Interpretation

This is a useful positive signal but not a main claim:

- The strongest 3-point result is on only 121 clips / 16 subjects.
- The large COUGHVID and TosCOVID targets remain far below the requested 3-5 point gain.
- KD seed ensembling is not novel enough by itself.
- The result is still useful as auxiliary evidence that KD posterior averaging can help on tiny external targets.

## Decision

Do not promote prediction ensembling to the main ICASSP 2027 innovation.

Use it as:

1. an auxiliary stability ablation,
2. a sanity check that the metric code can detect true positive gains,
3. a fallback figure/table if the final paper becomes a guarded-transfer / failure-slice paper.

The next high-value path remains unchanged:

- for a positive method claim: run the HeAR PyTorch frozen embedding gate after gated-weight access;
- for a robust external validation claim: download/extract UKCOVID audio and run the prepared evaluation pipeline.
