# 5.102 Symptom-risk equalized KD hard gate

## Purpose

5.101 found that symptom metadata is a strong confound signal in both source and COUGHVID, and that source symptom risk groups can drive the existing risk-matching KD training path.

This note runs one conservative full hard gate:

> Symptom-risk equalized KD with source symptom groups, env risk weight 0.1, sigmoid ramp 10, seed 7.

No grid search was run.

## Interpretation

This is a mixed/negative hard gate.

Positive:

- COUGHVID improves over source-only by +1.49 points.
- COUGHVID also slightly improves over Candidate F artifact-risk KD.
- The method did not collapse on source validation/test.

Negative:

- The planned continuation threshold was at least +2 points on COUGHVID; this run does not reach it.
- TosCOVID drops below source-only by -0.88 points.
- The external pattern is still COUGHVID-positive/TosCOVID-negative, similar to Candidate F.
- The selected checkpoint occurs before the symptom risk penalty becomes strong, which weakens the mechanistic claim that risk equalization is earning the gain.

## Claim Status

Not claimable.

This does not satisfy the ICASSP evidence standard because:

- it does not reach the requested 3-5 point improvement;
- it fails the "do not hurt TosCOVID" hard gate;
- the positive COUGHVID gain is smaller than the prior symptom-slice post-hoc gate;
- one seed is insufficient, and the first seed already misses the continuation criteria.

## Next Implication

Do not tune `env-risk-weight` blindly.

The current source-only/COUGHVID/TosCOVID evidence now shows a repeated pattern:

- symptom/artifact risk mechanisms can help COUGHVID modestly;
- TosCOVID remains unsolved or worsens.

The next useful route should not be another scalar risk weight. Better options:

1. Acquire/evaluate a second symptom-rich external target with audio, especially UKCOVID or Cambridge, to see whether the symptom-confound idea generalizes beyond COUGHVID.
2. Move to a representation mechanism with stronger external priors, such as a foundation audio encoder if access/download is approved.
3. If staying local, pivot toward a failure-aware external target audit paper rather than a 3-5 point improvement claim.

Guarded deployment can reject this model on TosCOVID using the earlier artifact-composition rule, but the aggregate gain would still be well below the requested 3-5 points, so it is supporting analysis only.
