### Phase 3: 新 target 结果出来后 1 周内

目标：决定最终 claim。

分支 A：新 target 复制 COUGHVID pattern

- KD gain weak or unstable；
- calibration/probe/AUROC disagreement persists；
- guard selection unreliable；
- readiness 变成 Go for ShiftAudit。

最终 claim：

> CoughKD-ShiftAudit demonstrates that ultra-light cough KD under dataset shift requires multi-evidence failure auditing; aggregate AUROC alone is insufficient for deployment claims.

分支 B：某个方法在 COUGHVID + 新 target 都稳定变强

- 转回方法贡献；
- 但需要额外 ablation 和 statistical test；
- 当前概率较低。

分支 C：新 target 任务语义不同，例如 CODA TB / FluSense

- 论文 claim 改为 generic cough/audio deployment reliability；
- 不再写 COVID external validation；
- 需要在 introduction 和 experiments 中明确 task shift。

### Phase 4: 投稿前 4-6 周

目标：完成正式稿。

任务：

1. 替换为 ICASSP 2027 official author kit；
2. 压缩到 4 pages + optional references page；
3. 更新 references metadata，尤其 ShiftKD / Coughprint / OPERA / respiratory KD；
4. 检查 AI content disclosure policy；
5. 完成 anonymous / double-blind 检查；
6. 固定随机种子和 artifact table；
7. 生成 final figures at publication resolution；
8. 最后运行 readiness audit。
