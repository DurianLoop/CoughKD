## 数据集优先级

1. **Cambridge COVID-19 Sounds / ComParE CCS**：最高优先级，第二个独立 COVID cough external target。
2. **CODA TB / TBcough**：非 COVID 疾病迁移目标；如果 Cambridge 慢，可转成 generic cough deployment reliability。
3. **DiCOVA Track-1**：Coswara-derived auxiliary protocol；必须 overlap audit，不能直接当独立外部。
4. **FluSense/HF respiratory event audio**：只适合 event/representation stress，不适合作为疾病筛查主证据。
