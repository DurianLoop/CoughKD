# 5.59 UK COVID Audio Post-Download Readiness Tooling

日期：2026-06-03

## 本轮目的

上一轮已经把 UK COVID-19 Vocal Audio Dataset 推进到 metadata/manifest/overlap ready。本轮目标是消除后续音频解压后的路径不确定性，并把“大音频下载后如何进入模型评估”变成自动检查流程。

## 新增/修改

### 1. `scripts/build_ukcovid_manifest.py`

新增参数：

```text
--recursive-audio-search
```

作用：在 `dataset-dir` 下递归索引 `.wav/.flac/.ogg/.webm/.mp3` 文件名。如果 split zip 解压后不是直接放在根目录，而是在子目录中，manifest builder 仍然能根据 `cough_file_name` / `three_cough_file_name` 找到真实路径。

已通过 smoke test：

```text
runs/smoke_ukcovid_builder/manifest_recursive.csv
written: 2
labels: covid_positive=1, healthy=1
```

### 2. `scripts/check_ukcovid_audio_ready.py`

新增 post-download readiness 检查脚本。它会检查：

- 25 个 Zenodo split archive 文件是否存在且大小完整；
- `manifests/ukcovid_open_test_external.csv` 中的 22,242 个唯一 wav 文件名是否能在 `D:\CoughKD\external\ukcovid_open` 下递归找到；
- 如果全部 ready，则给出正式 manifest rebuild + onboarding 命令；
- 如果不 ready，则给出续传下载命令。

当前运行结果：
