# 5.39 Novelty Matrix：从 CoughKD-FailBench 收缩到 CoughKD-ShiftAudit

## 为什么改名

本轮检索发现 `FailBench` 已经作为通用 failure-mode benchmark 名称出现。虽然它不是咳嗽音频或 KD 领域的工作，但继续使用 `CoughKD-FailBench` 容易造成命名冲突，也会让审稿人觉得我们在借一个更大的 benchmark 名称。

因此建议工作名改为：

> **CoughKD-ShiftAudit: Failure Cartography for Ultra-Light Cough Audio Distillation under Dataset Shift**

中文：

> **CoughKD-ShiftAudit：面向数据集漂移的超轻量咳嗽音频蒸馏失败图谱与部署审计**

这比 `FailBench` 更准确：

- `Shift` 对齐 Coswara -> COUGHVID 的跨数据集问题；
- `Audit` 强调我们是评估协议/审计贡献，不是假装提出强 SOTA 方法；
- `Failure Cartography` 作为副标题，表达 slice/bootstrap/probe/calibration 多证据失败图谱。

## Novelty Matrix

| Related work | 已经做了什么 | 我们不能 claim 什么 | 我们还能 claim 什么 |
|---|---|---|---|
| ShiftKD, Neural Networks 2025 | 系统 benchmark KD under distribution shift，覆盖 30+ KD 方法、多个通用视觉/分类 benchmark，分析 shift 下 KD 是否有效 | first KD benchmark under distribution shift；first to show KD can fail under shift | 专门面向 respiratory/cough audio、ultra-light deployment、COVID/cough screening-style task 的 KD shift audit；加入 external AUROC、calibration、domain/task probe、slice-level negative transfer、bootstrap target-composition sensitivity 和 latency |
| Respiratory sound ensemble KD, Interspeech 2025 | 在 ICHBI respiratory sound classification 上做 ensemble teacher soft-label KD，证明 architecture-agnostic KD 可以提升性能并达到 SOTA | first KD for respiratory sound；first architecture-agnostic respiratory KD；first soft-label respiratory distillation | 我们不证明 KD 一定有效，而是分析 cough dataset shift 下 KD 何时弱/失败；任务从 ICHBI respiratory classification 转向 Coswara -> COUGHVID cough transfer 与部署审计 |
| Coughprint, IEEE TIM 2025 | 从 speech foundation model embeddings 蒸馏 cough representations，强调 edge-compute 和多下游 cough measurement tasks | first cough representation distillation；first edge cough representation model | 我们研究的是 disease-screening-like cough transfer 中，large/teacher-to-ultra-light student 的外部泛化、校准、负迁移和 target composition sensitivity |
| OPERA, NeurIPS 2024 D&B | 构建 respiratory acoustic foundation model pretraining and benchmarking system，含多源呼吸音频和 19 个 downstream tasks | first respiratory acoustic foundation benchmark；first respiratory audio benchmark | 我们不做 foundation pretraining，而是评估已有 teacher/student KD 在端侧部署和 dataset shift 下的可靠性 |
| Dataset cartography / ASR diversity tax, 2026 | 用 dataset cartography 审计 ASR 中单一 WER 指标掩盖的人群/声学失败，并提出 sample difficulty index | first audio model auditing；first dataset cartography for speech/audio | 我们将类似“多证据审计”的思想用于 cough KD under shift，关注 KD 方法 ranking、target subsets、calibration/probe/external AUROC 不一致 |

## 当前最稳的贡献表述

建议写成四点：

1. **Problem reframing**  
   我们不声称“咳嗽可诊断 COVID”，而是把问题定义为：
   > How reliable is knowledge distillation for ultra-light cough audio students under external dataset shift?

2. **CoughKD-ShiftAudit protocol**  
   建立一个包含 Coswara source、COUGHVID target、subject-disjoint training、multi-seed training、external evaluation、slice stress test、bootstrap target-subset stress test、probe/calibration/deployment metrics 的审计协议。

3. **Failure cartography evidence**  
   发现当前 KD variants 的整体收益很弱，但不同 target slices/subsets 上的 post-hoc best 差异明显；也就是说“存在局部可获益空间”，但当前无标签目标域信号无法可靠识别。

4. **Metric disagreement finding**  
   校准、Brier/NLL、domain probe、task probe、external AUROC、COVID sensitivity@95 specificity 和 efficiency 之间并不一致。单一指标无法支持部署 claim。

## 当前证据是否足够 ICASSP？

现在的证据已经足够支撑一个 **workshop / short analysis** 风格的故事，但对 ICASSP main track 仍偏薄，主要因为：

- 只有一个独立外部目标 COUGHVID；
- 没有第二 respiratory/cough external target；
- 还没有把 OPERA/Coughprint/stronger teacher 纳入外部对比；
- 当前结论是 negative/analysis，需要非常扎实的实验协议和图表支撑。

最低增强条件：

1. 至少再加一个外部目标数据集，优先 Cambridge COVID-19 Sounds / ComParE CCS；
2. 如果拿不到 Cambridge，加入 DiCOVA 但明确它是 Coswara-derived，不当独立外部；
3. 再补一个非 COVID cough transfer target，比如 cough type / wet-dry / TB cough 数据集，用于证明这是 generic cough deployment reliability；
4. 主文图表至少包括：
   - main table；
   - calibration vs AUROC scatter；
   - domain probe vs AUROC scatter；
   - 25-slice delta gap；
   - bootstrap delta distribution；
   - efficiency compression figure。
