# 5.124 Semantic-router submission readiness gate

## Purpose

Continue toward the ICASSP 2027 objective by adding an automated readiness gate for the current semantic-router claim package.

The older `scripts/audit_submission_readiness.py` was built for the earlier audit-only paper and can report `GO` even though the current semantic-router claim still lacks third-target validation. This round adds a stricter semantic-router-specific audit.

## Script added

- `scripts/audit_semantic_router_submission_readiness.py`

The script checks:

1. ICASSP main draft artifacts:
   - `paper_icassp2027/main.tex`
   - `paper_icassp2027/main.pdf`
   - `paper_icassp2027/main_pdftotext.txt`
2. Main-paper claim anchors:
   - `semantic-constrained router`
   - `target metadata semantics can act as`
   - `+3.75`
   - `+3.99`
   - `inverted semantic controls collapse`
   - `moderate-label rather than few-shot`
3. Main compile log:
   - no `Undefined`, `LaTeX Warning`, `Package Warning`, `Error`, or `Overfull` matches.
4. Semantic-router evidence artifacts:
   - paper tables;
   - semantic-control paired bootstrap;
   - semantic-vs-controller bootstrap.
5. Supplement artifacts:
   - `runs/semantic_router_supplement/main.pdf`
   - `runs/semantic_router_supplement/main_pdftotext.txt`
   - supplement compile log.
6. Novelty boundary artifacts:
   - Markdown novelty matrix;
   - LaTeX novelty matrix.
7. Third-target readiness:
   - UKCOVID semantic-router readiness JSON.
8. Final-format warning:
   - ICASSP 2027 final author kit/page rules still need re-check.
