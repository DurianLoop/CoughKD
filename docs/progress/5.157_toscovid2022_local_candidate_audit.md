# 5.157 TosCOVID 2022 Local Candidate Audit

Date: 2026-06-15

## Purpose

Check whether the locally present `external/tos_covid19/tos-covid-2022.csv` can be used as a non-duplicate local third target under the user's local-dataset-first constraint.

## Result

Added `scripts/audit_toscovid2022_local_candidate.py`.

Generated:

- `runs/toscovid2022_local_candidate_audit/TOSCOVID2022_LOCAL_CANDIDATE_AUDIT.md`
- `runs/toscovid2022_local_candidate_audit/toscovid2022_local_candidate_audit.json`

Verdict:

`METADATA_ONLY_NOT_LOCAL_AUDIO_TARGET`

Evidence:

- TosCOVID 2022 table has 139,986 rows and 139,986 unique IDs.
- Local TosCOVID audio directories contain only `audio_2021`.
- Local `audio_2021` has 5,796 audio files.
- TosCOVID 2022 IDs have 0 overlap with local 2021 audio matching keys.
- Therefore TosCOVID 2022 is present locally as a testing/metadata table, not as a local cough-audio target.

`NO_LOCAL_THIRD_TARGET_READY`

## Windows write behavior

While rerunning gates, a parallel gate invocation exposed a Windows read/write race on JSON outputs. I changed the gate file writer to avoid producing locked `.tmp` artifacts: it now skips writes when content is unchanged and otherwise retries direct writes. Final gate reruns were done sequentially.
