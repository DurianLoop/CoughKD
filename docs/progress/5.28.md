# 2026-05-28 Stage 3 Target-Consistent Distillation 结果分析

## 1. 结论

Stage 3 的 target-consistent distillation 和 Stage 2/2b 的 sample-weighted SA-KD 不一样。

Stage 2/2b 的模式是：

```text
Coswara in-domain ↑
COUGHVID external ↓
domain probe AUC ↑
task probe AUC ↓
```

Stage 3 的模式是：

```text
Coswara in-domain ≈ vanilla KD
COUGHVID external macro AUROC ≈ vanilla KD
COUGHVID COVID AUROC 小幅 ↑
domain probe AUC 小幅 ↓
task probe AUC 小幅 ↑
```

所以 Stage 3 不是失败方向，但当前提升太小，不能直接作为论文主结果。它更像一个初步正信号：**target-domain consistency 比 source-domain sample filtering 更合理，但还需要严格 control 和更强设置验证。**

## 2. Coswara in-domain 结果

| method | acc | macro-F1 | AUROC | AUPRC | ECE | Brier |
|---|---:|---:|---:|---:|---:|---:|
| vanilla KD | 0.3565 | 0.2363 | 0.5577 | 0.2507 | 0.0591 | 0.7583 |
| TCD low | 0.5082 | 0.2213 | 0.5600 | 0.2518 | 0.1345 | 0.6741 |
| TCD mid | 0.5070 | 0.2202 | 0.5610 | 0.2523 | 0.1334 | 0.6728 |
| TCD conf | 0.5095 | 0.2224 | 0.5600 | 0.2514 | 0.1355 | 0.6748 |

观察：

- TCD 没有破坏 Coswara AUROC，略高于 vanilla KD；
- accuracy 明显上升，但 macro-F1 低于 vanilla KD，说明预测分布可能偏向大类；
- ECE 比 vanilla KD 差，说明校准仍是问题；
- Brier 明显更低，可能是概率分布变得更平滑，但这不能单独作为结论。

## 3. COUGHVID external 结果

| method | acc | macro AUROC | macro AUPRC | COVID AUROC | Healthy AUROC | Resp AUROC | COVID AUPRC |
|---|---:|---:|---:|---:|---:|---:|---:|
| CE baseline | 0.3332 | 0.5198 | 0.3449 | 0.5373 | 0.5185 | 0.5036 | 0.0869 |
| vanilla KD | 0.2358 | 0.5142 | 0.3433 | 0.5179 | 0.5101 | 0.5146 | 0.0771 |
| TCD low | 0.6219 | 0.5140 | 0.3424 | 0.5198 | 0.5064 | 0.5158 | 0.0793 |
| TCD mid | 0.6257 | 0.5142 | 0.3423 | 0.5208 | 0.5063 | 0.5155 | 0.0793 |
| TCD conf | 0.6200 | 0.5140 | 0.3423 | 0.5196 | 0.5068 | 0.5157 | 0.0793 |

精确比较：

```text
vanilla KD macro AUROC = 0.5141898101
TCD mid macro AUROC    = 0.5142147270
diff                   = +0.0000249169

vanilla KD COVID AUROC = 0.5178882816
TCD mid COVID AUROC    = 0.5208380718
diff                   = +0.0029497902
```

观察：

- TCD mid 仅仅“擦边”超过 vanilla KD macro AUROC，幅度几乎可以忽略；
- COVID AUROC 有 `+0.0030`，这是 Stage 3 最值得保留的正信号；
- 但 CE baseline 仍然更强：macro AUROC `0.5198`，COVID AUROC `0.5373`；
- TCD 的 accuracy 很高，但这不应作为主指标，因为 COUGHVID 类别不平衡，accuracy 容易被大类主导。

## 4. Domain probe 结果

| model | dataset-domain AUC | task-label AUC |
|---|---:|---:|
| CE student | 0.7238 | 0.5836 |
| vanilla KD | 0.7145 | 0.6347 |
| TCD low | 0.7136 | 0.6393 |
| TCD mid | 0.7148 | 0.6388 |
| TCD conf | 0.7132 | 0.6395 |

观察：

- TCD low/conf 的 domain AUC 略低于 vanilla KD；
- TCD 的 task-label AUC 全部高于 vanilla KD；
- 这和 Stage 2/2b 相反，说明 target consistency 没有破坏任务表征；
- 但变化幅度很小，不能单 seed 下做强 claim。

## 5. 训练动态

TCD 的 target consistency loss 很小：

```text
target loss ≈ 0.015 - 0.021
target confidence ≈ 0.37 - 0.39
```

confidence-gated 版本的问题：

```text
threshold = 0.45
epoch 5 keep ratio ≈ 0.03
epoch 6 keep ratio ≈ 0.11
```

也就是说，`0.45` 阈值太高，大部分 target 样本没有参与 consistency。下一轮如果继续做 confidence gating，阈值应降到 `0.35` 或 `0.30`。

## 6. 当前判断

TCD 方向值得继续，但不能直接扩 3 seeds。原因：

1. macro AUROC 增益几乎为 0；
2. COVID AUROC 有小幅提升，但仍远低于 CE baseline；
3. domain/task probe 有正向信号，但幅度小；
4. 目前缺少关键 control：**source-only continuation**。

最关键的问题是：

> TCD 的小幅变化到底来自 COUGHVID-adapt target consistency，还是来自从 vanilla KD checkpoint 继续训练 6 个 epoch？

如果没有 source-only continuation control，Stage 3 的结论不严谨。

## 7. 下一步计划

### 7.1 先做 Stage 3 control

新增一个对照：

```text
source-only continuation
```

设置：

- init student = vanilla KD student；
- init teacher = PANNs teacher；
- source = Coswara train；
- target_weight = 0；
- epochs = 6；
- lr = 5e-5；
- 其他参数与 Stage 3 完全一致。

目的：

> 判断 TCD 的变化是否只是继续训练造成的。

如果 source-only continuation 和 TCD 结果一样，那么 target consistency 没有贡献。

如果 TCD 明显优于 source-only continuation，才说明 target-domain consistency 有效。

### 7.2 再做 Stage 3b 强 target consistency

当前 target loss 太小，target 信号可能不够。下一轮建议：

| variant | target weight | confidence threshold | 说明 |
|---|---:|---:|---|
| source_only | 0.00 | 0.00 | 继续训练对照 |
| tcd_strong | 0.60 | 0.00 | 更强 target consistency |
| tcd_very_strong | 1.00 | 0.00 | 检查 target loss 上限 |
| tcd_conf035 | 0.60 | 0.35 | 更合理的 confidence gating |

### 7.3 成功标准

Stage 3b 先不看 accuracy，严格看：

1. macro AUROC 是否超过 source-only continuation；
2. macro AUROC 是否超过 vanilla KD `0.5142` 至少 `+0.003`；
3. COVID AUROC 是否超过 vanilla KD `0.5179` 至少 `+0.005`；
4. task probe AUC 是否不低于 vanilla KD `0.6347`；
5. domain probe AUC 是否不高于 CE student `0.7238`。

如果 Stage 3b 仍然只有 `+0.000x` 级别提升，不要扩 seeds，直接转分析路线。

### 7.4 如果 Stage 3b 成功

如果 `tcd_strong` 或 `tcd_conf035` 明显优于 source-only continuation：

1. 跑 seeds `7, 11, 23`；
2. 汇总 mean ± std；
3. 再补 calibration：ECE、Brier、reliability diagram；
4. 再考虑第二个 target dataset，例如 DiCOVA。

### 7.5 如果 Stage 3b 失败

如果 Stage 3b 没有明显优于 source-only continuation，则论文主线应改为：

> **When Does Knowledge Distillation Fail for Ultra-Light Cough Audio Models under Dataset Shift?**

这时贡献点是：

1. 系统复现 PANNs -> ultra-light student；
2. 证明 in-domain KD 与 external generalization 不一致；
3. 证明 naive shortcut weighting 会破坏任务表征；
4. 证明 target consistency 只能带来极小收益；
5. 用 domain probe / external eval / calibration 解释 cough audio dataset shift 下 KD 的局限。

这个方向更适合 ICASSP 或 IEEE JBHI/TASLP 风格，不一定适合 AAAI 方法主文。
