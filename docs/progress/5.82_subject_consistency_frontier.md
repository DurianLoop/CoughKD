# 5.82 Subject-Consistency Frontier

## Purpose

Check a second low-cost route that could be more defensible than plain seed ensembling:

> If a target contains multiple cough clips per subject, can subject-consistent posterior aggregation produce a stable 3-5 point gain?

This is relevant because UKCOVID and TosCOVID both contain multiple recordings per participant, and Virufyseg contains many segmented clips per original subject.

## Literature Boundary

This route is not obviously novel as a standalone method. Recent and prior cough-audio work already uses multiple audio recordings per participant, subject-level evaluation, or aggregation across recordings/modalities. More importantly, the 2024 Nature Machine Intelligence analysis argues that audio-only COVID classifiers did not show improved screening over symptom checkers, raising the evidential bar for any positive claim.

## Decision

Subject-consistency aggregation is not a claimable main innovation yet.

Reasons:

- On the larger TosCOVID subject-level target, the best gain is only about `+0.27` to `+0.33` points and statistically weak.
- On Virufyseg, point estimates exceed 3-5 points but the effective sample size is only 16 subjects and bootstrap CI lower bounds are negative.
- Prior cough-audio work already contains multi-recording or subject-level aggregation ideas, so the novelty is not strong enough without a larger risk-control mechanism.

Keep subject-consistency as an evaluation protocol and a future UKCOVID-ready component, not as the primary ICASSP 2027 method claim.
