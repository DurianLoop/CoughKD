# 2026-05-24 Stage 2 结果分析与 Stage 2b 调整

## 1. 结论先行

Stage 2 已完整跑完。第一版 SA-KD 的结果是：

> **Coswara in-domain 有提升，但 COUGHVID external 没有提升；domain probe AUC 也没有下降。**

这说明当前第一版 shortcut weighting 不能直接支撑“减少 shortcut 表征传递”的强 claim。它更像一个有用的负结果：

1. Coswara 与 COUGHVID 的声学统计差异极强；
2. 低阶统计特征训练出的 domain probe AUC 达到 `0.9991`；
3. 当前 domain/full 权重过于激进，平均 KD 权重太低；
4. 过度压制 teacher signal 后，虽然 in-domain AUROC 上升，但 external AUROC 下降。

因此下一步不应该马上扩 seed，而应该先做 **Stage 2b：温和权重实验**。

所以当前不能写：

> SA-KD reduces shortcut representation.

> The first shortcut-weighted variant reveals that naive suppression of domain-typical samples is insufficient and may harm transferable task representations.

## 3. 对当前方法的判断

第一版方法不是完全失败，它给了一个重要发现：

> 咳嗽音频跨数据集差异极强，简单地根据 domain-typicality 降低 KD 权重，会让 student 失去 teacher 中仍然有用的任务表征。

也就是说，shortcut 特征不一定是纯副作用。它可能与音频质量、咳嗽强度、采样协议、症状分布等因素纠缠在一起。直接压掉 domain-typical 样本，可能同时压掉了对分类仍有帮助的信号。

这对论文方向反而是有价值的：它说明我们不能做 naive shortcut removal，而要做更细的 **teacher-signal selection**。

## 4. Stage 2b 调整

新增脚本：

```text
scripts/run_shortcut_audited_stage2b_windows.cmd
```

它测试三种更温和的权重：

### 4.1 tempered full

```text
floor = 0.30
quality_power = 0.50
domain_power = 0.25
stability_power = 0.50
```

目的：保留一半以上 teacher signal，只轻度降低高风险样本。

### 4.2 tempered domain

```text
floor = 0.30
quality_power = 0.0
domain_power = 0.25
stability_power = 0.0
```

目的：单独验证 domain risk 是否有用，但避免像 Stage 2 那样过度压制。

### 4.3 mild full

```text
floor = 0.50
quality_power = 0.25
domain_power = 0.15
stability_power = 0.25
```

目的：更接近 regularization，而不是强 filtering。

## 6. Stage 2b 成功标准

优先级从高到低：

1. COUGHVID-test macro AUROC 不低于 vanilla KD `0.5142`；
2. COVID AUROC 不低于 vanilla KD `0.5179`；
3. Coswara in-domain AUROC 不低于 vanilla KD `0.5577`；
4. domain probe AUC 低于 vanilla KD `0.7145`，或至少不高于 CE `0.7238`；
5. task probe AUC 不明显低于 vanilla KD `0.6347`。

最理想结果：

```text
external AUROC ↑
domain probe AUC ↓
task probe AUC ≈ preserved
```

可接受结果：

```text
external AUROC ↑
domain probe AUC unchanged
```

不可接受结果：

```text
external AUROC ↓
task probe AUC ↓
domain probe AUC ↑
```

Stage 2 第一版属于不可接受结果，因此必须做 Stage 2b。
