# 5.47 2026 Literature Re-check and Claim Boundary

## 本轮目的

在已有实验已经转向 CoughKD-ShiftAudit 后，需要重新确认创新边界：我们的贡献不能和 2025/2026 附近的 KD under shift、respiratory KD、cough representation distillation、respiratory foundation model benchmark 撞车。

## 新查到/重新确认的强相关工作

### 1. ShiftKD: Benchmarking Knowledge Distillation under Distribution Shift

链接：

- https://www.sciencedirect.com/science/article/pii/S089360802500718X

关键信息：

- Neural Networks 2025。
- 系统 benchmark KD under distribution shift。
- 覆盖 30+ KD 方法。
- 讨论 diversity shift / correlation shift 等通用 shift setting。

因此我们不能 claim：

- first KD benchmark under distribution shift；
- first to show KD can fail under shift；
- first systematic KD failure study。

我们还能 claim：

- 面向 cough / respiratory audio deployment 的 domain-specific audit；
- ultra-light cough student 的 external, calibration, probe, slice/bootstrap, latency 联合审计；
- COVID-era cough datasets 中 target composition 和 evaluation unit 对 KD ranking 的影响。

### 2. Improving Respiratory Sound Classification with Architecture-Agnostic Knowledge Distillation from Ensembles

链接：

- https://www.isca-archive.org/interspeech_2025/toikkanen25_interspeech.html
- https://www.isca-archive.org/interspeech_2025/toikkanen25_interspeech.pdf

关键信息：

- Interspeech 2025。
- 在 ICBHI respiratory sound classification 上做 ensemble teacher soft-label KD。
- 目标是提升 respiratory sound classification performance，并报告 SOTA score。

因此我们不能 claim：

- first KD for respiratory sound；
- first soft-label respiratory KD；
- first architecture-agnostic respiratory KD。

我们还能 claim：

- 我们不是证明 KD 必然有效，而是审计 cough dataset shift 下 KD 的不稳定性；
- 我们的任务不是 ICBHI lung sound classification，而是 Coswara -> COUGHVID/Virufy 的 cough screening-style external transfer；
- 我们关注部署可靠性，包括 target-unlabeled guard failure、clip-vs-subject evaluation unit sensitivity、calibration/probe/efficiency disagreement。

### 3. Coughprint: Distilled Cough Representations from Speech Foundation Model Embeddings

链接：

- https://colab.ws/articles/10.1109%2Ftim.2025.3568985

关键信息：

- IEEE TIM 2025。
- 从 speech foundation model embeddings 蒸馏 cough representations。
- 强调 edge-compute student models，可用于多种 cough measurement / identification / classification tasks。

因此我们不能 claim：

- first cough representation distillation；
- first edge cough representation model；
- first distillation for cough representation。

我们还能 claim：

- 我们研究的是 disease-screening-like cross-dataset cough transfer 下，KD 是否可靠；
- 我们不是只证明 student 保留 teacher representation，而是审计不同 KD 策略在外部目标、目标切片、subject-level aggregation、calibration 和 probe 之间是否一致。

### 4. OPERA: Towards Open Respiratory Acoustic Foundation Models

链接：

- https://proceedings.neurips.cc/paper_files/paper/2024/hash/2f803abdcad9de35b45d5a656dade45c-Abstract-Datasets_and_Benchmarks_Track.html
- https://opera-benchmark.github.io/

关键信息：

- NeurIPS 2024 Datasets and Benchmarks。
- 构建 respiratory acoustic foundation model pretraining and benchmarking system。
- 包含约 136K samples、400+ hours、19 downstream respiratory health tasks。

因此我们不能 claim：

- first respiratory acoustic foundation benchmark；
- first broad respiratory audio benchmark；
- foundation-model-level contribution。

我们还能 claim：

- 我们不是做 foundation model，而是对已有 teacher/student distillation 进行 deployment reliability audit；
- 我们的独特角度是 ultra-light cough student 在 dataset shift 下的 failure cartography。

### 5. DiCOVA / COVID cough challenge literature

链接：

- https://dicova2021.github.io/
- https://dicovachallenge.github.io/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC8610834/

关键信息：

- DiCOVA 2021 是 cough COVID detection challenge。
- Track-1 约包含 75 COVID-positive / 965 non-COVID subjects，评估核心是 AUC。
- challenge 强调 cough/breath/speech 的 COVID acoustic signature 可能性，但也存在数据不平衡和泛化风险。

因此我们不能 claim：

- first COVID cough audio external evaluation；
- first AUC-based cough COVID benchmark。

我们还能 claim：

- 我们不是追求 DiCOVA-style best AUC，而是用 deployment audit 解释 KD under shift 的失效和指标冲突；
- DiCOVA 如果后续加入，只能作为 Coswara-related auxiliary protocol，不能替代 Cambridge 这类独立外部集。

## 当前最稳创新边界

一句话：

> CoughKD-ShiftAudit is not a new KD algorithm that consistently beats baselines; it is a deployment-oriented failure audit protocol for ultra-light cough audio distillation under dataset shift.

可写贡献：

1. **Domain-specific reframing**  
   把 COVID cough 模型从“诊断有效性”转为“超轻量 cough student 的跨数据集蒸馏可靠性”。

2. **Multi-evidence audit protocol**  
   不是只看 aggregate AUROC，而是联合 external AUROC/AUPRC、calibration、domain/task probes、sensitivity@95 specificity、slice stress、bootstrap target subset、clip-vs-subject unit、params/latency/model size。

3. **Failure cartography evidence**  
   在 COUGHVID 上 KD 增益极弱；Virufy stress targets 显示 post-hoc best method 会随 target size、preprocessing granularity 和 evaluation unit 改变；target-unlabeled guard 不能可靠追踪最优 KD 策略。

4. **Deployment warning**  
   对 cough audio KD，降低 shortcut/probe 指标或改善 calibration 不等价于 external AUROC 提升；单一指标不足以支撑端侧部署 claim。

## 不能写的贡献

不能写：

- We propose the first KD method for respiratory/cough audio。
- We benchmark KD under distribution shift for the first time。
- We introduce the first cough representation distillation model。
- Our method achieves robust SOTA COVID cough diagnosis。
- Virufy proves external generalization。

## 当前投稿强度判断

当前证据能支持一个结构清楚的 analysis / audit paper 雏形，但 ICASSP main-track 仍需补强：

- 至少再拿一个大规模独立外部目标，优先 Cambridge COVID-19 Sounds / ComParE CCS；
- 或者加入 DiCOVA + 非 COVID cough transfer target，并明确 claim 改成 generic cough deployment reliability；
- 需要将现有 figures/tables 放入完整论文骨架，并补 related-work citations。
