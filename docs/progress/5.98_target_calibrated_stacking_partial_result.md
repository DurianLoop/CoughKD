# 5.98 Target-calibrated stacking partial result

## Purpose

After rejecting metadata leaf gates and label-free confidence routing, this note tests a stronger non-metadata baseline:

> use a small labeled target calibration split to learn a global model combination from existing prediction CSVs, then evaluate on held-out target examples.

This is not a novelty claim by itself. COVID cough papers already use ensembles and meta-models, and recent CoughSense / drift-adaptive / DNDT-DNDF work makes generic adaptation claims crowded. The value of this audit is to determine whether the current model pool contains enough complementary signal to justify a new training-time or calibration-time mechanism.

## Protocol

Targets:

- COUGHVID
- TosCOVID
- Virufyseg

Candidates:

- `calib_best_single`: choose the best single method on the calibration split.
- `logistic_stacking`: train a class-balanced logistic regression on concatenated log-probabilities from the available methods.

Calibration fractions:

- 0.3
- 0.5

Regularization values for stacking:

- C = 0.1
- C = 1.0

Repeats:

- 120

The first attempted 300-repeat wider grid was stopped because logistic stacking took too long for the desired low-cost loop. The smaller grid completed and is sufficient to test for a strong signal.

## Interpretation

This is a partial positive result, not a claimable innovation.

Positive signal:

- TosCOVID shows a meaningful target-calibrated stacking gain: about +3.1 to +3.6 points over source-only with 30-50% target calibration labels.
- Virufyseg also improves, but it remains too small for a main claim.

Negative signal:

- COUGHVID does not benefit from global stacking. The best mean gain is only about +0.5 points, with a negative confidence bound.
- Calibration-picked best single methods are weak on large targets.
- The result is target-specific rather than cross-target stable.

This means current model predictions contain complementary information for TosCOVID, but not enough for a broad method claim. It also strengthens the earlier conclusion that COUGHVID's useful signal is slice-specific, while TosCOVID's useful signal is global-combinational.

## Claim status

Not claimable yet.

The result suggests a possible next mechanism, but it must be more than ordinary stacking:

> a target-calibrated transfer controller that chooses between slice-gated deployment when reliable metadata exists and global stacked deployment when metadata is unavailable but calibration labels reveal complementary model errors.

However, this would need:

1. a principled selection rule, not post-hoc target-specific choice;
2. a second independent target beyond COUGHVID/TosCOVID;
3. stronger held-out confidence intervals;
4. a novelty argument that is not just ensemble stacking.
