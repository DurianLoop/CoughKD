# 2026-05-31 COUGHVID Slice Guard Audit

## 1. Why This Was Run

Independent external data is still the main missing piece. To avoid waiting passively, I ran a proxy multi-target stress test on COUGHVID by slicing the target test set using metadata available without target labels:

- cough detector confidence high / low;
- sex male / female;
- age young / old;
- self-reported respiratory condition true / false;
- all test set.

This does not replace an independent target dataset. It only tests whether CoughKD-Guard behaves sensibly across multiple target shifts already present inside COUGHVID.

## 2. Script and Artifact

New script:

```cmd
python scripts\summarize_coughvid_slice_guard.py
```

Output:

The script reuses existing full-COUGHVID prediction files, so it does not retrain or rerun inference.

## 5. Effect On The ICASSP Direction

CoughKD-Guard remains possible, but the current scoring rule is too weak to claim.

The direction can continue only if one of these becomes true:

1. An independent external target, such as Cambridge COVID-19 Sounds / ComParE CCS, confirms that the guard avoids negative transfer across datasets.
2. A stronger target-unlabeled score is developed and validated, preferably using model disagreement, source/target representation density, and class-prior shift rather than only confidence/entropy.
3. The paper is reframed as an analysis paper: **KD negative transfer is common and hard to predict in ultra-light cough audio deployment**, with CoughKD-Guard as a preliminary audit rather than the main method.

## 6. Literature Pressure

The target-unlabeled model selection idea is not new in general. Relevant prior work includes:

- Deep Embedded Validation (DEV), ICML 2019: target-risk estimation for unsupervised domain adaptation.
- Unsupervised risk estimation with domain-invariant predictors, ICML 2020.
- DAPPER, 2021: label-free performance estimation for mobile sensing under domain shift.
- Source-free / unsupervised domain adaptation model selection and transferability-estimation literature.

Therefore, the novelty cannot be "we select a model without target labels." It must be much narrower:

> respiratory/cough audio + ultra-light KD + negative-transfer audit + deployment-oriented model choice.

## 7. Next Step

The immediate next experiment should not add more KD losses. Instead:

1. Obtain an independent external target.
2. Evaluate the existing fixed checkpoint set.
3. Re-run `summarize_coughkd_guard_multitarget.py`.
4. If guard_score correlation remains below 0.5 or selection collapses to one conservative method, stop CoughKD-Guard as a method claim and pivot to an analysis paper.
